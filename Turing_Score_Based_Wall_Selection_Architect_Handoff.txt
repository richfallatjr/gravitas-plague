6. SCAN CLEANSING
======================================================================

The scan is complete before this runs. Freeze Array(wallCandidates.values) and
Array(floorCandidates.values) on MainActor. Never let the model read the live
dictionaries while ARKit mutates them.

Do not discard an early wall merely because lastUpdated is old. In a 360 scan,
the first wall naturally stops updating while the user faces later walls.
Removed ARKit anchors are already removed from WallPlaneManager. Treat age as a
confidence feature, not a hard stale cutoff.

Hard cleansing:

  - reject non-finite vectors/dimensions
  - reject width < 0.55 m or height < 0.75 m
  - normalize right/up/normal
  - force up toward gravity +Y
  - force normal toward the captured viewer position
  - rebuild right = normalize(cross(up, normal))
  - merge duplicate coplanar fragments
  - consolidate floor fragments at the same height
  - sort canonical walls deterministically and alias wall-000, wall-001, ...

Recommended merge tolerances:

```swift
enum TuringStoryScanCleanserTuning {
    static let minimumWallWidth: Float = 0.55
    static let minimumWallHeight: Float = 0.75
    static let maximumNormalAngleDegrees: Float = 8.0
    static let maximumPlaneSeparationMeters: Float = 0.10
    static let maximumProjectedFragmentGapMeters: Float = 0.25
    static let maximumFloorHeightDeltaMeters: Float = 0.08
}
```

Core merge predicate:

```swift
private func canMerge(
    _ lhs: WallCandidate,
    _ rhs: WallCandidate
) -> Bool {
    let normalDot = abs(simd_dot(lhs.normal, rhs.normal))
    let minimumNormalDot = cos(
        TuringStoryScanCleanserTuning.maximumNormalAngleDegrees
            * .pi / 180
    )
    guard normalDot >= minimumNormalDot else { return false }

    let planeSeparation = abs(
        simd_dot(rhs.center - lhs.center, lhs.normal)
    )
    guard planeSeparation <= TuringStoryScanCleanserTuning
        .maximumPlaneSeparationMeters else {
        return false
    }

    let delta = rhs.center - lhs.center
    let horizontalDistance = abs(simd_dot(delta, lhs.right))
    let horizontalReach = lhs.width * 0.5 + rhs.width * 0.5
    let verticalDistance = abs(simd_dot(delta, lhs.up))
    let verticalReach = lhs.height * 0.5 + rhs.height * 0.5

    return horizontalDistance <= horizontalReach +
            TuringStoryScanCleanserTuning.maximumProjectedFragmentGapMeters &&
        verticalDistance <= verticalReach +
            TuringStoryScanCleanserTuning.maximumProjectedFragmentGapMeters
}
```

For each merge group, project all four corners of every source wall into the
seed wall basis, union minX/maxX/minY/maxY, then reconstruct one canonical
center and extent. Do not average widths and lose coverage.

```swift
private func corners(of wall: WallCandidate) -> [SIMD3<Float>] {
    let halfRight = wall.right * (wall.width * 0.5)
    let halfUp = wall.up * (wall.height * 0.5)
    return [
        wall.center - halfRight - halfUp,
        wall.center + halfRight - halfUp,
        wall.center - halfRight + halfUp,
        wall.center + halfRight + halfUp
    ]
}
```

Floor consolidation:

  1. Keep floor.isUsableFloor.
  2. Keep floors below viewer by the existing 1.0...2.4 m classifier.
  3. Group floors whose worldY differs by <= 0.08 m.
  4. Pick the group with greatest summed area, then stability.
  5. Use area-weighted worldY and report total area/source count.

Do not ask Foundation Models to choose the floor.

8. SLOT GENERATION AND DETERMINISTIC BASE SCORE
======================================================================

The LLM must never invent localX/localY. Code generates candidate slots.

For every canonical wall and prop:

  - resolve width/height
  - resolve center world Y from canonical floor
  - convert world Y to wall-local Y
  - solve legal horizontal center range from wall width and margin
  - sample X at 0.20 m intervals plus zero and both extremes
  - calculate rect and padded rect
  - reject overlap with fixed occupancy
  - calculate deterministic geometry features
  - assign a stable slot ID

as existing Horde/story portals and kill switches. Exclude the four planned

```swift
private func sampledXCenters(maxX: Float) -> [Float] {
    guard maxX > 0.001 else { return [0] }

    var values: Set<Int> = [
        0,
        Int((maxX * 100).rounded()),
        Int((-maxX * 100).rounded())
    ]
    var x = -maxX
    while x <= maxX {
        values.insert(Int((x * 100).rounded()))
        x += 0.20
    }
    return values.sorted().map { Float($0) / 100.0 }
}
```

Suggested deterministic score is 0...100 and is evidence for the LLM, not the
final global layout decision:

```swift
private func baseScore(
    wallStability: Float,
    viewAlignment: Float,
    facesViewer: Float,
    edgeClearance: Float,
    verticalCoverage: Float,
    distanceMeters: Float
) -> Float {
    let edgeScore = min(1, max(0, edgeClearance / 0.60))
    let distanceScore = max(0, 1 - abs(distanceMeters - 2.0) / 4.0)

    return min(100, max(0,
        wallStability * 15 +
        viewAlignment * 25 +
        facesViewer * 15 +
        edgeScore * 15 +
        verticalCoverage * 20 +
        distanceScore * 10
    ))
}
```

```swift
actor TuringStoryWallLayoutPlanner {
    private let runner: any TuringFoundationQueryRunning

    init(
        runner: any TuringFoundationQueryRunning =
            TuringFoundationModelsRunner()
    ) {
        self.runner = runner
    }

    func plan(
        snapshot: TuringStoryRoomLayoutSnapshot
    ) async throws -> TuringStoryWallLayoutPlan {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.sortedKeys]
        let data = try encoder.encode(snapshot.dataset)
        let datasetJSON = String(decoding: data, as: UTF8.self)
        let templateURL = try TuringResourceLoader.resourceURL(
            resourcePath: "Turing/Prompts/storyWallLayoutPlanner.txt"
        )
        let template = try String(
            contentsOf: templateURL,
            encoding: .utf8
        )
        let prompt = template.replacingOccurrences(
            of: "{{layoutDatasetJSON}}",
            with: datasetJSON
        )

        let raw = try await runner.runPrompt(
            prompt,
            purpose: "storyWallLayoutPlanner"
        )

        print("""
        [TuringWallPlanner] raw response
          scanID: \(snapshot.dataset.scanID)
          responseUTF16: \(raw.utf16.count)
        [TuringWallPlannerRaw] BEGIN
        \(raw)
        [TuringWallPlannerRaw] END
        """)

        let json = try TuringJSONSanitizer.extractSingleTopLevelObject(
            from: raw
        )
        return try JSONDecoder().decode(
            TuringStoryWallLayoutPlan.self,
            from: json
        )
    }
}
```

10. VALIDATION - CODE REMAINS PHYSICAL AUTHORITY
======================================================================

Validation is not subjective layout scoring. It enforces referential and
physical integrity:

  - schemaVersion == 1
  - response scanID equals current snapshot scanID
  - every assignment propID is known
  - every slotID exists in runtimeSlotByID
  - slot.propID matches assignment.propID
  - assignment priority matches TuringStoryPropID.priority
  - no prop appears twice
  - no slot appears twice
  - every prop is either assigned or explicitly unplaced, never both
  - assignments are processed by priority, regardless of response array order
  - selected padded rectangles do not overlap on the same wall
  - selected rectangles do not overlap fixed occupancy
  - the referenced live wall still exists before commit
  - the live wall has not moved beyond a small scan-drift tolerance

Suggested drift tolerance at commit:

  center delta <= 0.10 m
  normal delta <= 8 degrees

Core overlap validation:

```swift
private func validatePairwiseOverlap(
    selected: [TuringStoryRuntimeSlot],
    propByID: [TuringStoryPropID: TuringStoryLayoutProp]
) throws {
    for i in selected.indices {
        for j in selected.indices where j > i {
            let lhs = selected[i]
            let rhs = selected[j]
            guard lhs.wallUUID == rhs.wallUUID else { continue }

            let lhsPadding = propByID[lhs.propID]!.occupancyPadding
            let rhsPadding = propByID[rhs.propID]!.occupancyPadding
            let lhsRect = WallLocalRect(
                minX: lhs.localX - lhs.width * 0.5,
                minY: lhs.localY - lhs.height * 0.5,
                maxX: lhs.localX + lhs.width * 0.5,
                maxY: lhs.localY + lhs.height * 0.5
            ).expanded(by: lhsPadding)
            let rhsRect = WallLocalRect(
                minX: rhs.localX - rhs.width * 0.5,
                minY: rhs.localY - rhs.height * 0.5,
                maxX: rhs.localX + rhs.width * 0.5,
                maxY: rhs.localY + rhs.height * 0.5
            ).expanded(by: rhsPadding)

            guard !lhsRect.overlaps(rhsRect) else {
                throw TuringStoryWallLayoutError.selectedSlotsOverlap(
                    lhs.slotID,
                    rhs.slotID
                )
            }
        }
    }
}
```

Do not treat ideal spacing as a validation failure. It is a score/preference.

11. POSTER MIGRATION - REQUIRED TO HONOR PRIORITY
======================================================================

The poster is currently the UI used to enter Story mode and may already be
locked before the full room scan. That is compatible with user interaction but
not with the final priority order.

Required Story behavior:

  1. Keep the current poster visible while the user performs the 360 scan.
  2. During dataset construction, exclude the existing wallPoster occupancy
     from fixedOccupancy because poster is one of the four planned props.
  3. Do not mutate anything while Foundation Models plans.
  4. Validate the complete plan first.
  5. Preload/prepare all three USDZ bundles before commit.
  6. Immediately before commit, reset the provisional Story poster placement.
  7. Commit door, window, walkie shelf, then poster.
  8. Rebuild the poster at the selected priority-4 slot.

Add a planned placement API instead of calling choosePlacement again:

```swift
extension WallMountedPosterUIController {
    @discardableResult
    func commitPlannedStoryPlacement(
        _ placement: WallPosterPlacement
    ) -> Bool {
        guard placementState == .notPlaced,
              committedPlacement == nil,
              let transform = worldTransform(for: placement) else {
            return false
        }

        root.isEnabled = false
        rebuildPosterIfNeeded(
            width: placement.width,
            height: placement.height
        )
        guard let occupancyID = registerPosterOccupancy(
            placement: placement
        ) else {
            return false
        }

        root.setTransformMatrix(transform, relativeTo: nil)
        currentPlacement = placement
        committedPlacement = CommittedWallPosterPlacement(
            candidatePlacement: placement,
            worldTransform: transform,
            occupancyID: occupancyID
        )
        placementState = .locked
        hasRegisteredOccupancy = true
        root.isEnabled = true
        return true
    }
}
```

Coordinator shape:

```swift
@MainActor
final class TuringStoryWallLayoutCoordinator {
    enum State: String {
        case idle
        case cleansing
        case planning
        case validating
        case preparingAssets
        case committing
        case complete
        case failed
    }

    private(set) var state: State = .idle
    private var task: Task<Void, Never>?
    var isPlanningOrCommitting: Bool {
        ![.idle, .complete, .failed].contains(state)
    }

    func planAndCommit(
        wallManager: WallPlaneManager,
        occupancyRegistry: WallPropOccupancyRegistry,
        viewerPosition: SIMD3<Float>,
        viewerForward: SIMD3<Float>,
        atmosphere: PortalHDRIAtmosphere,
        reason: String
    ) {
        guard task == nil else { return }

        let walls = Array(wallManager.wallCandidates.values)
        let floors = Array(wallManager.floorCandidates.values)
        let occupancy = Array(occupancyRegistry.recordsByID.values)

        task = Task { @MainActor [weak self] in
            guard let self else { return }
            do {
                state = .cleansing
                let snapshot = try cleanser.makeSnapshot(
                    walls: walls,
                    floors: floors,
                    occupancy: occupancy,
                    viewerPosition: viewerPosition,
                    viewerForward: viewerForward
                )

                state = .planning
                let firstPlan = try await planner.plan(snapshot: snapshot)

                state = .validating
                let validated: TuringStoryValidatedLayout
                do {
                    validated = try validator.validate(
                        firstPlan,
                        snapshot: snapshot,
                        liveWalls: wallManager.wallCandidates
                    )
                } catch {
                    let revisedPlan = try await planner.replan(
                        snapshot: snapshot,
                        validationError: error.localizedDescription
                    )
                    validated = try validator.validate(
                        revisedPlan,
                        snapshot: snapshot,
                        liveWalls: wallManager.wallCandidates
                    )
                }

                state = .preparingAssets
                try await prepareAllAssets()

                state = .committing
                try await commitInPriorityOrder(
                    validated,
                    atmosphere: atmosphere
                )

                state = .complete
                task = nil
            } catch {
                state = .failed
                task = nil
                print("""
                [TuringWallPlanner] failed
                  reason: \(reason)
                  error: \(error.localizedDescription)
                  fallbackUsed: false
                """)
            }
        }
    }
}
```

The coordinator needs injected references to the four controllers. Do not make
new controller instances. Do not create a second WallPlaneManager or occupancy
registry.

Commit transaction:

```swift
private func commitInPriorityOrder(
    _ layout: TuringStoryValidatedLayout,
    atmosphere: PortalHDRIAtmosphere
) async throws {
    // Complete plan was already validated and all assets were prepared.
    doorController.reset(reason: "globalStoryLayoutCommit")
    windowController.reset(reason: "globalStoryLayoutCommit")
    walkieController.reset(reason: "globalStoryLayoutCommit")
    posterController.resetPlacement(reason: "globalStoryLayoutCommit")

    for assignment in layout.assignments.sorted(by: {
        $0.propID.priority < $1.propID.priority
    }) {
        switch assignment.propID {
        case .door:
            try await doorController.commitPlannedPlacement(
                assignment.doorPlacement,
                atmosphere: atmosphere
            )
        case .window:
            try await windowController.commitPlannedPlacement(
                assignment.windowPlacement,
                atmosphere: atmosphere
            )
        case .walkieShelf:
            try await walkieController.commitPlannedPlacement(
                assignment.walkiePlacement
            )
        case .poster:
            guard posterController.commitPlannedStoryPlacement(
                assignment.posterPlacement
            ) else {
                throw TuringStoryWallLayoutError.commitFailed("poster")
            }
        }
    }
}
```

If any commit unexpectedly fails after staging, reset all four planned props
and report failure. Do not leave a partial layout and do not invoke independent
selectors as a fallback.

======================================================================
15. FAILURE POLICY
======================================================================

Allowed failures:

  - no usable floor after scan
  - no canonical walls after cleansing
  - Foundation Models unavailable
  - malformed JSON after one JSON repair
  - invalid physical plan after one explicit replan
  - referenced wall changed before commit
  - asset preparation failed
  - planned placement commit failed

On failure:

  - leave the provisional poster visible if commit has not begun
  - leave all preexisting placements untouched if commit has not begun
  - clear the scanning HUD and show a concise placement failure state
  - write all debug artifacts
  - do not call old choosePlacement methods
  - do not make up coordinates
  - do not silently run a deterministic fallback
  - allow an explicit user retry using a new scanID

18. IMPLEMENTATION SUMMARY
======================================================================

The existing scan and physical placement math are useful. The architectural
change is to stop letting four controllers independently claim wall space.

The final production path is:

  existing Horde-style 360 scan
  -> immutable WallPlaneManager snapshot
  -> canonical floor and consolidated wall dataset
  -> code-generated placement slots with physical feature scores
  -> one Foundation Models whole-room layout request
  -> slot-ID-only response
  -> deterministic physical validation
  -> staged resource preparation
  -> atomic priority commit:
       door
       window
       walkie shelf
       poster

That gives Foundation Models enough structured context to make a coherent room
composition while keeping every meter, floor lock, transform, and collision
decision grounded in the existing RealityKit/ARKit code.
