Architect Handoff: Story Mode Walkie-Talkie Wall Bundle, Script Trigger Audio Anchor
================================================================================

Goal
----
Implement a Story Mode wall-mounted prop bundle that contains:

- a walkie-talkie
- a shelf
- a succulent prop
- a dad photo frame

The bundle should be imported as one USDZ so the art layout is preserved. The app
must place the bundle on a real detected wall, avoid the existing wall poster UI
and portal occupancy, default the bundle center to 4 feet off the floor, and route
all Turing/Big Mike audio to the walkie-talkie geometry. The current TTS debug UI
stays for now, but its audio output should spatialize from the walkie-talkie once
the bundle is present.

This is the beginning of the Script Trigger system. Do not replace Qwen, the TTS
debug UI, audiobook mode, Foundation prompting, or the compute-gap/filler system
in this patch. The patch should create the prop anchor target that those systems
can play through.


Required Bundle Naming Convention
---------------------------------
Use stable ASCII entity names inside the USDZ. The runtime should find these names
recursively after loading the USDZ.

Recommended USDZ filename:

    turing_story_wall_bundle_v1.usdz

Recommended resource destination:

    Gravitas Plague/Gravitas Plague/Turing/Props/turing_story_wall_bundle_v1.usdz

Root entity in USDZ:

    TuringStoryWallBundle_Root

Required child entity names:

    TuringStoryWallBundle_Shelf
    TuringStoryWalkieTalkie_Root
    TuringStoryWalkieTalkie_AudioEmitter
    TuringStoryWalkieTalkie_IconAnchor
    TuringStoryDadFrame_Root
    TuringStoryDadFrame_AudioEmitter
    TuringStoryDadFrame_IconAnchor
    TuringStorySucculent_Root

Optional child names:

    TuringStoryWalkieTalkie_ButtonPTT
    TuringStoryWalkieTalkie_SpeakerGrille
    TuringStoryDadFrame_PhotoPlane
    TuringStoryDadFrame_Glass
    TuringStoryShelf_Surface
    TuringStoryShelf_OccupancyBounds

Naming rules:

- Do not rely on autogenerated Blender/Maya names like Cube.001.
- Do not put spaces in entity names.
- Do not rename these after export; RealityKit lookup depends on stable strings.
- The audio emitter child should be a tiny Empty/Xform located at the acoustic source.
- The icon anchor child should be a tiny Empty/Xform placed slightly in front of the
  object where a billboard icon/HUD affordance should attach.
- The walkie-talkie audio emitter is the default Turing speech source.
- The dad frame audio emitter is reserved for later script triggers or photo-frame
  interaction audio. Do not route Big Mike TTS to dad frame by default.

Scale and axis expectations:

- Author in meters.
- Bundle local origin should be the bundle center at the wall contact plane.
- +Y is up.
- +Z should point outward from the wall toward the viewer if possible.
- The bundle should sit just in front of the wall; app will add a small depth offset.
- Keep the visual width/height reasonable for wall placement; recommended initial
  occupancy size is about 0.65m wide by 0.45m high unless real asset dimensions
  demand otherwise.


Placement Requirements
----------------------
The walkie bundle should behave like a wall prop, not a head-locked UI:

1. Install in the immersive Story scene root.
2. Use detected vertical walls from WallPlaneManager.
3. Prefer visible walls in front of the player, same selection style as poster.
4. Avoid overlap with the wall poster and horde portals using WallPropOccupancyRegistry.
5. Default center height to 4 feet off the detected floor.
6. If no floor candidate is available, fall back to the wall center Y, but log it.
7. Register occupancy so future posters/portals avoid this bundle.
8. Once locked, do not keep moving it every frame; only update if wall refinement for
   the same wall is explicitly supported and tested.

Default height:

    4.0 feet = 1.2192 meters

Recommended placement tuning:

    preferredCenterHeightMeters = 1.2192
    minBottomClearanceMeters = 0.60
    wallMarginMeters = 0.10
    depthOffset = 0.025
    occupancyPaddingMeters = 0.12
    defaultWidthMeters = 0.65
    defaultHeightMeters = 0.45

The 4-foot default is the bundle center, not the shelf bottom. If the visual shelf
looks too low/high after testing, adjust the bundle asset origin or the controller
tuning, but keep the rule explicit.

The poster already places a wall object with floor-aware center height and registers

```swift
private func bestSlot(
    on wall: WallCandidate,
    wallManager: WallPlaneManager
) -> WallPosterPlacement? {
    let size = WallPosterMetrics.posterSize(for: wall)
    let width = size.x
    let height = size.y
    let floorY = wallManager.bestFloorCandidate(near: wall)?.worldY
    let desiredWorldY: Float

    if let floorY {
        let preferredCenter =
            floorY + WallPosterPlacementTuning.preferredCenterHeightMeters
        let minCenter =
            floorY +
            WallPosterPlacementTuning.minBottomClearanceMeters +
            height * 0.5

        desiredWorldY = max(preferredCenter, minCenter)
    } else {
        desiredWorldY = wall.center.y
    }

    let desiredLocalY: Float

    if abs(wall.up.y) > 0.05 {
        desiredLocalY = (desiredWorldY - wall.center.y) / wall.up.y
    } else {
        desiredLocalY = 0
    }

    let maxX = max(
        0,
        wall.width * 0.5 - width * 0.5 - WallPosterPlacementTuning.wallMarginMeters
    )
    let maxY = max(
        0,
        wall.height * 0.5 - height * 0.5 - WallPosterPlacementTuning.wallMarginMeters
    )
    let clampedY = min(max(desiredLocalY, -maxY), maxY)

    let candidateXs: [Float] = [
        0,
        -maxX * 0.55,
        maxX * 0.55,
        -maxX,
        maxX
    ]

    // score candidates and reject occupancy overlap
}
```

Proposed controller shape:

```swift
import Combine
import Foundation
import RealityKit
import simd

@MainActor
final class TuringStoryWalkieBundleController: ObservableObject {
    enum BundleError: LocalizedError {
        case missingUSDZ(String)
        case missingRequiredEntity(String)
        case noWallManager
        case noPlacement
    }

    struct Anchors {
        let bundleRoot: Entity
        let walkieRoot: Entity
        let walkieAudioEmitter: Entity
        let walkieIconAnchor: Entity?
        let dadFrameRoot: Entity?
        let dadFrameAudioEmitter: Entity?
        let dadFrameIconAnchor: Entity?
    }

    private(set) var root = Entity()
    private var loadedBundleRoot: Entity?
    private(set) var anchors: Anchors?

    private weak var wallManager: WallPlaneManager?
    private weak var occupancyRegistry: WallPropOccupancyRegistry?

    private let occupancyID = UUID()
    private(set) var placement: TuringStoryWallBundlePlacement?
    private(set) var isPlaced = false

    init() {
        root.name = "TuringStoryWalkieBundle_WorldRoot"
        root.isEnabled = false
    }

    func installIfNeeded(
        sceneRoot: Entity,
        wallManager: WallPlaneManager,
        occupancyRegistry: WallPropOccupancyRegistry
    ) {
        self.wallManager = wallManager
        self.occupancyRegistry = occupancyRegistry

        if root.parent == nil {
            sceneRoot.addChild(root)
        }

        print("[TuringWalkieBundle] installed")
    }

    func placeOnBestWallIfNeeded(
        playerPosition: SIMD3<Float>,
        playerForward: SIMD3<Float>
    ) async -> Bool {
        guard !isPlaced else { return true }
        guard let wallManager else {
            print("[TuringWalkieBundle] ERROR missing wallManager")
            return false
        }

        do {
            let bundle = try await loadBundleIfNeeded()
            let anchors = try resolveAnchors(in: bundle)
            self.anchors = anchors

            guard let placement = choosePlacement(
                wallManager: wallManager,
                playerPosition: playerPosition,
                playerForward: playerForward
            ) else {
                print("[TuringWalkieBundle] no valid wall placement yet")
                return false
            }

            guard let transform = worldTransform(
                placement: placement,
                wallManager: wallManager
            ) else {
                print("[TuringWalkieBundle] ERROR could not compute transform")
                return false
            }

            root.setTransformMatrix(transform, relativeTo: nil)
            root.isEnabled = true
            self.placement = placement
            self.isPlaced = true
            registerOccupancy(placement: placement)

            anchors.walkieAudioEmitter.components.set(SpatialAudioComponent())
            anchors.dadFrameAudioEmitter?.components.set(SpatialAudioComponent())

            print(
                """
                [TuringWalkieBundle] placement committed
                  wallID: \(placement.wallID)
                  localX: \(placement.localX)
                  localY: \(placement.localY)
                  width: \(placement.width)
                  height: \(placement.height)
                  preferredCenterHeightMeters: \(TuringStoryWalkieBundleTuning.preferredCenterHeightMeters)
                  walkieAudioEmitter: \(anchors.walkieAudioEmitter.name)
                  dadFrameAudioEmitter: \(anchors.dadFrameAudioEmitter?.name ?? "nil")
                """
            )

            return true
        } catch {
            print(
                """
                [TuringWalkieBundle] ERROR placement failed
                  error: \(error.localizedDescription)
                """
            )
            return false
        }
    }
}
```

```swift
extension Entity {

        if name == targetName {
```

```swift
private func loadBundleIfNeeded() async throws -> Entity {
```

World transform:

```swift
private func worldTransform(
    placement: TuringStoryWallBundlePlacement,
    wallManager: WallPlaneManager
) -> simd_float4x4? {
    guard let wall = wallManager.wallCandidates[placement.wallID] else {
        return nil
    }

    let position =
        wall.center +
        wall.right * placement.localX +
        wall.up * placement.localY +
        wall.normal * placement.depthOffset

    var matrix = matrix_identity_float4x4
    matrix.columns.0 = SIMD4<Float>(wall.right.x, wall.right.y, wall.right.z, 0)
    matrix.columns.1 = SIMD4<Float>(wall.up.x, wall.up.y, wall.up.z, 0)
    matrix.columns.2 = SIMD4<Float>(wall.normal.x, wall.normal.y, wall.normal.z, 0)
    matrix.columns.3 = SIMD4<Float>(position.x, position.y, position.z, 1)
    return matrix
}
```

This mirrors `PortalDoorController.applyTransformFromPlacement(...)`, which sets
the wall-local transform using wall right/up/normal and then verifies the normal.

```swift
enum TuringScriptTriggerTarget: String, Sendable {

struct TuringScriptTriggerAnchor: Sendable {
```

  names and does not silently fall back to head-locked/global audio.
- Dad frame anchors are resolved and logged but not used as Big Mike audio source.

  walkie emitter is resolved
- implement full Script Trigger behavior in this patch
- add a second room-scanning system
