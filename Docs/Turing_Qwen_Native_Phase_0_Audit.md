## B. Autoregressive hot path

7. **One-row entry — STATIC.** Segment generation enters `TuringQwenNativeBaseCloneEngine.generateDynamicCodebook` at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneEngine.swift:1068-1288`. The initial row is predictor-only at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneEngine.swift:1112-1171`. Each later row is produced by the policy-aware `TuringQwenNativeTalkerForwardRunner.forwardOneStep` at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeTalkerLayer.swift:283-441`, which invokes `TuringQwenNativeCodePredictor.generateCodeGroupCached` at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:264-402`.

8. **Per-row loops — STATIC.** The semantic loop is `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneEngine.swift:1173-1274`. Every subsequent row runs 28 talker layers at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeTalkerLayer.swift:333-354`, then one predictor prefill and 14 successor selections at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:308-380`. Predictor prefill and one-step paths each loop over five layers at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorForwardRunner.swift:241-255,317-332`.

9. **Operation count — STATIC structural count; runtime kernel count UNAVAILABLE.** One complete subsequent row has 28 talker decoder-layer passes, one talker final norm/head and selection, one predictor prefill plus 14 one-token forwards, 75 predictor decoder-layer passes, and 15 predictor heads/selections. Under the benchmark's greedy policy, sampling expresses one talker `argMax` plus 15 predictor `argMax` operations (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSampler.swift:13-50,129-143`; `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:330-379`). Each layer expresses normalization, Q/K/V projections, reshape/transpose, RoPE, cache update, attention, output projection, residual, and gated MLP work (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeTalkerLayer.swift:444-714`; `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorForwardRunner.swift:347-624`). There is no retained, reproducible source-expression counter or Metal trace, so an exact MLX-operation/kernel/dispatch number is unavailable. MLX may fuse or split source expressions; this audit does not relabel an estimate as a measured kernel count.

10. **Materialization/readback inventory — STATIC.** Current baseline behavior is:

    - Prompt assembly first evaluates its inputs/mask/trailing state at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneInputBuilder.swift:326-337`. Initial prompt execution then synchronously evaluates each of 28 layer outputs with both cache tensors, followed by `finalHidden` and `finalLastHidden` (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeTalkerLayer.swift:140-187`). Greedy initial sampling also evaluates logits at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneEngine.swift:735-755`.
    - Every talker row needs a host token for EOS/stop logic. Greedy sampling calls `.item(Int.self)`; sampled talker selection calls `checkedEval` and reads the full Float logits vector with `.asArray(Float.self)` (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSampler.swift:35-50,71-125`).
    - Temperature/top-p predictor selection likewise materializes a full vocabulary vector for each sampled residual. Greedy predictor residuals stay as MLX arrays while the row graph is assembled.
    - Predictor state starts with a host-created `MLXArray([firstCodecToken])` at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:326`; it is not a retained device token.
    - A row's concatenated token array is materialized only for debug/fixture checks during generation (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:380-400`), but completed segment export calls `dynamicCodebook.rows.map(\.tokenIDs)` at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneEngine.swift:804-806`; `tokenIDs` falls back to one `.asArray(Int.self)` per row at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:4-11`.
    - `.performance` disables mode-controlled per-layer eval/cache-clear/full-token/disk-row work (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativePerformanceMode.swift:70-80`), but it does not disable the unconditional prompt containment evals, token decisions, segment export readbacks, sampler print, or eight-row checkpoints described in answers 58-59.
    - No `asyncEval` call exists in the production native generation package. A complete synchronization/readback counter is not instrumented, so its total is unavailable.

11. **Which calls are barriers — STATIC.** `item`, `asArray`, synchronous `eval`, and `checkedEval` establish completion/materialization boundaries. `item` evaluates before scalar access at `ThirdParty/LocalSwiftPackages/mlx-swift/Source/MLX/MLXArray.swift:159-177,331-334`; `asArray` evaluates before copying bytes to the host at `ThirdParty/LocalSwiftPackages/mlx-swift/Source/MLX/MLXArray+Bytes.swift:113-135`; synchronous and asynchronous eval entry points are `ThirdParty/LocalSwiftPackages/mlx-swift/Source/MLX/Transforms+Eval.swift:11-45,96-164`. Shape reads, Swift timing, graph construction, concatenation, slicing, arithmetic, and cache-update expressions do not by themselves prove host completion. `asyncEval` schedules evaluation without a synchronous host wait, but it is not used in this production loop.

## C. KV cache and recurrent state

12. **Talker cache — STATIC.** `TuringQwenNativeKVCache` owns 28 layer structs with key/value MLX arrays, logical length, and capacity at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeKVCacheStore.swift:4-33`. Prompt setup allocates each pair to `promptLength + max(maxNewRows, 1) + 8` at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeKVCacheStore.swift:35-74`; every generated row writes the next slice at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeKVCacheStore.swift:77-115`.

13. **Predictor cache — STATIC.** Each semantic row creates a fresh five-layer predictor cache because predictor autoregression is local to that row. Every layer stores key/value, logical length, and capacity at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorCache.swift:4-32`. The two-token prefill allocates five K/V pairs with capacity 34 (`blockCapacity = 32`, then `length + blockCapacity`) at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorCache.swift:46-86`; 14 one-step writes grow logical length to 16 at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorCache.swift:89-127`.

14. **Concatenating caches — STATIC.** Neither active cache grows with `concatenate`. Both use indexed/slice assignment (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeKVCacheStore.swift:101-104`; `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorCache.swift:113-116`). The Swift MLX setter lowers to functional slice-update expressions at `ThirdParty/LocalSwiftPackages/mlx-swift/Source/MLX/MLXArray+Indexing.swift:352-390,833-870`, so this is not proof of in-place mutation.

15. **Growth allocation — STATIC with backend limitation.** A valid request does not reallocate capacity: the backing shapes are fixed and overflow throws. Swift's MLX slice-assignment syntax is functional graph/update work, however, so source inspection does not prove zero backend storage allocation or true in-place mutation (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeKVCacheStore.swift:94-114`; `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorCache.swift:106-126`).

16. **Preallocation — STATIC.** Talker cache is preallocated for the request maximum plus eight guard positions. Predictor cache is also preallocated, but to 34 positions for a mathematical maximum of 16; it therefore overallocates 18 positions per K/V tensor. No accepted Phase 2 exact-capacity change remains (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorCache.swift:47,65-85`).

17. **Masks — STATIC.** The 1-D target attention mask is built and evaluated once per request at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneInputBuilder.swift:281-337`, but the talker forward path does not read `promptInputs.attentionMask`; repository search finds no talker consumer of that field. The full-prompt causal mask that is actually used is rebuilt inside each of 28 talker layer calls at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeTalkerLayer.swift:567-596`. Predictor's two-token prefill mask is built once per segment, not per row, at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSegmentRuntimeCache.swift:47-69`; one-token predictor steps need no causal mask. The speech decoder rebuilds a full-sequence mask inside every decoder transformer layer at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSpeechDecoder.swift:568-602,998-1013`.

18. **Positions — STATIC.** Talker one-step RoPE arrays for the row budget and predictor RoPE arrays for positions 0-15 are built once per segment at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSegmentRuntimeCache.swift:16-70`. They are not rebuilt every semantic row, but they are not resident across requests. Full-prompt talker RoPE is rebuilt per layer at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeTalkerLayer.swift:567-581`.

19. **Immutable recomputation — STATIC.** Lane-local static prompt contexts cache role/tag/speaker/reference-text/reference-code embeddings by voice, variant, language, and reference-window key at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneEngine.swift:980-986,1023-1054`; their construction is `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneInputBuilder.swift:187-279`. Target text embedding, target/reference composition, target mask, and trailing target state are request-dependent and rebuilt at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneInputBuilder.swift:281-347`. The tokenizer object and its vocabulary/merges are reloaded per request at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneEngine.swift:899-914`; this remains an unmeasured candidate.

## D. Code predictor

20. **Passes per row — STATIC.** One two-token prefill plus 14 one-token forwards: 15 predictor forwards and 75 decoder-layer passes per complete row (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:308-380`; `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorForwardRunner.swift:241-255,317-332`).

21. **Small MLX work — STATIC shape, runtime launches UNAVAILABLE.** Each of the 75 layer passes expresses many small dependent operations, as listed in answer 9. A host talker-token decision eventually realizes the dependency chain, but only a Metal/MLX trace can say how many kernels MLX fuses or launches. No such trace is retained, so the requested independent launch count is unavailable.

22. **Invariant tensors and actual lifetime — STATIC.** Predictor config and resolved model weights are resident (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorForwardRunner.swift:4-100`). The fixed two-token mask and RoPE positions 0-15 are invariant in value but only cached per segment (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSegmentRuntimeCache.swift:47-69`). Grouped-query repeat indices and attention scale are recreated in attention calls at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorForwardRunner.swift:479-509,566-587,749-764`. They are not members of resident resolved weights.

23. **Recreated buffers — STATIC.** Each semantic row creates prefill hidden/projection results, ten predictor K/V zero buffers, 15 short layer-result arrays, 14 successor states, a 16-token array, attention/normalization/projection/MLP graph temporaries, grouped-head index arrays, and Swift wrappers. The prefill mask and RoPE tables are reused from the segment cache. The 34-position K/V capacity remains (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictor.swift:308-400`; `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeCodePredictorCache.swift:46-127`).

24. **Persistent/indexed workspace — STATIC.** K/V shapes are fixed and populated through slice updates, but Swift/MLX treats each update as a new graph value; the source does not prove a mutable in-place persistent buffer. Predictor state cannot carry into the next semantic row without changing model semantics because every row starts a new within-frame residual-code prediction. A reusable request-local workspace remains a candidate requiring exact-output and performance qualification.

25. **Fusion/compile feasibility — STATIC candidate, not implemented.** The installed MLX API exposes compiled functions, but no predictor compile owner or `compilationDisposition` exists in production. Vendored `CompiledFunction.call` is protected by one `NSLock` at `ThirdParty/LocalSwiftPackages/mlx-swift/Source/MLX/Transforms+Compile.swift:7-43`; a single shared compiled closure could serialize lanes, while a request-local owner could recompile. A long-lived lane-local owner is a plausible future experiment, not an accepted Phase 2 result.

26. **Installed transform APIs — STATIC.** Vendored MLX Swift identifies itself as 0.31.1 at `ThirdParty/LocalSwiftPackages/mlx-swift/Package.swift:213-220` and exposes `compile` overloads beginning at `ThirdParty/LocalSwiftPackages/mlx-swift/Source/MLX/Transforms+Compile.swift:145-220`. Safe reuse still requires a designed lane-local owner and device qualification.

## E. Speech decoding

27. **PCM cadence — STATIC.** The runtime produces one full PCM array per completed generated segment, never per semantic row/chunk. A Fresh worker renders all rows, then awaits one decode, then publishes the complete decoded segment at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeFreshInstanceScheduler.swift:372-488`.

28. **History behavior — STATIC.** `rowsForDecode` combines the last `min(referenceRows, 24)` reference rows with every generated row once at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenRenderedCodebookSegment.swift:137-175`. It does not repeatedly decode expanding generated prefixes or prior generated segments.

29. **Reprocessed history — STATIC.** Every segment reprocesses up to 24 reference rows (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenDecodeConfiguration.swift:3-5`). With 1,920 samples per row (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneDecodeTrimmer.swift:3-5`) at 24 kHz, that is at most 46,080 samples/1.92 seconds. It is retained for boundary quality; no listening result proves it unnecessary. Generated history is not redundantly reprocessed.

30. **CPU copy — STATIC.** After GPU evaluation, `asArray(Float.self)` creates a full host array and the surrounding `Array(prefix)` creates a second, expected-length host array at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSpeechDecoder.swift:247-263`. Reference trimming then creates a generated-only host array through `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSpeechDecodeCoordinator.swift:169-193` and `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeBaseCloneDecodeTrimmer.swift:6-30`.

31. **Generation/decode synchronization — STATIC.** Within one lane, all semantic rows finish before `decodeCoordinator.decode` is awaited (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeFreshInstanceScheduler.swift:384-455`). There is no same-segment generation/decode interleave.

32. **Overlap potential — STATIC.** `.currentOverlap` allows another lane's generation while the single decoder owns a completed segment (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeGPUAdmissionPolicy.swift:3-16,45-55`; current-mode admission is a no-op at `Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeGPUAdmissionController.swift:156-175`). The same worker cannot fetch its next item until decode/publication finishes, and the decoder actor permits one active run/decode owner (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSpeechDecodeCoordinator.swift:50-124`).

33. **Shortest safe window — UNAVAILABLE.** No incremental-decoder listening experiment exists; the fixture test only qualifies complete decode (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Tests/TuringQwenNativeTests/TuringQwenNativeSpeechDecoderFixtureTests.swift:6-45`) and its helper points to the separate VoiceDesign-bf16 artifact rather than the active Base-4bit model (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Tests/TuringQwenNativeTests/TuringQwenNativeSpeechDecoderFixtureTests.swift:48-70`). The active artifact declares decoder `sliding_window: 72` at `Gravitas Plague/TuringResources/Turing/Models/Qwen3TTS/Qwen3-TTS-12Hz-1.7B-Base-4bit/speech_tokenizer/config.json:11-43`, but the native decoder recomputes full-sequence Q/K/V/RoPE/mask inside every layer (`Gravitas Plague/Gravitas Plague/Turing/QwenNative/Sources/TuringQwenNative/TuringQwenNativeSpeechDecoder.swift:568-612,998-1038`). That metadata is not an implemented chunk boundary or evidence of artifact-free incremental decode.

## Phase 0 conclusions and Phase 1/2 disposition

The baseline still exposes plausible targets: required per-row talker host decisions; sampled full-vocabulary readbacks; one output readback per completed row; unconditional prompt containment evals; a host-created replacement for the first predictor token; hot-loop logging/checkpoints; 34-slot predictor cache allocation for 16 used positions; per-segment predictor mask/RoPE construction; repeated GQA indices/scales; prompt-layer mask/RoPE recreation; and request-local tokenizer construction.

Phase 1 and Phase 2 candidate edits explored parts of that list. They did not produce a retained, comparable schema-v2 result clearing the directive's at-least-10% gate, so they were rejected and fully reverted. Publishing an unretained preliminary timing as an accepted optimization would overclaim the evidence. Decoder streaming, lane/stream policy, tokenizer residency, playback I/O, and deeper compiled/fused graphs remain future work rather than silently mixed into this baseline.
