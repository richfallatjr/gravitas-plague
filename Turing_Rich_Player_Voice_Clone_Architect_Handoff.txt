======================================================================
1. OBJECTIVE
======================================================================

Add a second, completely distinct Qwen Base voice-clone family for Rich,
the main player character.

The first integration is a generated Rich voicePrompt reply to Big Mike's
existing incoming walkie prerecording:

  Big Mike incoming prerecording
    -> spatial playback from the authored walkie emitter
    -> Rich voicePrompt computes from the prerecording transcript
    -> Rich Qwen Fresh2 generation computes while Big Mike is still speaking
    -> Rich waits for the incoming prerecording's actual playback completion
    -> Rich outgoing open-comm sound plays globally
    -> Rich filler/generated speech plays globally and in order
    -> Rich outgoing send-comm sound plays globally after the last Rich clip

Rich is the player. Every Rich sound is nonspatial/global:

  - Rich generated TTS: global
  - Rich filler: global
  - Rich prerecording, if added later: global
  - Rich open-comm/send-comm: global

Do not attach Rich audio to:

  TuringStoryWalkieTalkie_AudioEmitter

Big Mike remains spatial at the walkie. Rich must sound as if the player's
own voice is being heard, not as if Rich is standing at the shelf.

There are two Rich output contexts:

  1. roomGlobal (DEFAULT)
     Used by voicePrompts triggered by objects in the room.
     No walkie open/send/static effects.

  2. walkieOutgoingGlobal (EXPLICIT OPT-IN)
     Used when Rich is replying through the walkie.
     Adds exactly one global open-comm before Rich content and exactly one
     global send-comm after Rich content.

The walkie context must never become the default.

   the same numerical rate as Big Mike, but it must not be inherited through a
   global default. Both character policies independently declare 0.85 so either
   voice can be tuned later without silently changing the other.

   Task.sleep may advance generated playback. Use AVAudioPlayer's delegate

8. Rich playback code must not call any AVAudioSession mutation API:

     AVAudioSession.sharedInstance().setCategory(...)

   must not reintroduce session ownership.

9. No fallback voice, no prerecorded dialogue fallback, no network runtime,
   and no fallback from two fresh Qwen instances to a shared lane or one
   instance.

10. Do not change Foundation Models dialogue parsing, Big Mike conversation,
    audiobook sectioning, Story prop placement, portal content, or HUD behavior.

Core generic implementation. This is the current Big Mike validation logic
with identity/path labels parameterized:

```swift
private func loadBaseCloneProfile(
    from bundleRoot: URL,
    profileResourcePath: String,
    expectedVoiceID: String,
    expectedCharacterID: String,
    logPrefix: String
) throws -> TuringQwenNativeCloneProfile {
    let profileRoot = bundleRoot.appendingPathComponent(
        profileResourcePath,
        isDirectory: true
    )

    guard FileManager.default.fileExists(atPath: profileRoot.path) else {
        throw TuringQwenNativeError.nativeGenerationNotImplemented(
            "Missing \(logPrefix) Base clone profile at \(profileRoot.path)."
        )
    }

    let metadataURL = profileRoot.appendingPathComponent("metadata.json")
    let metadata = try loadMetadata(from: metadataURL)

    guard metadata.voiceID == expectedVoiceID else {
        throw TuringQwenNativeError.invalidConfig(
            "Expected voiceID \(expectedVoiceID), got \(metadata.voiceID)."
        )
    }
    guard metadata.characterID == expectedCharacterID else {
        throw TuringQwenNativeError.invalidConfig(
            "Expected characterID \(expectedCharacterID), got \(metadata.characterID)."
        )
    }
    guard metadata.modelID == "qwen3-tts-12hz-1.7b-base-4bit",
          metadata.profileKind == "qwenBaseCloneReferenceProfile" else {
        throw TuringQwenNativeError.invalidConfig(
            "\(logPrefix) clone must target the Base 4-bit clone profile."
        )
    }
    guard metadata.allowFallback == false,
          metadata.allowPrerecordedDialoguePlayback == false else {
        throw TuringQwenNativeError.invalidConfig(
            "\(logPrefix) fallback/playback flags are invalid."
        )
    }

    guard let variantRef = metadata.variants.first(where: {
        $0.variantID == metadata.defaultVariantID
    }) else {
        throw TuringQwenNativeError.invalidConfig(
            "Missing default variant \(metadata.defaultVariantID)."
        )
    }

    let variantManifestURL = profileRoot.appendingPathComponent(variantRef.path)
    let variant = try loadVariant(from: variantManifestURL)
    guard variant.variantID == metadata.defaultVariantID,
          variant.voiceID == metadata.voiceID,
          variant.characterID == metadata.characterID,
          variant.kind == "baseCloneReferenceVariant",
          variant.allowFallback == false,
          variant.allowPrerecordedDialoguePlayback == false else {
        throw TuringQwenNativeError.invalidConfig(
            "\(logPrefix) variant metadata does not match its profile."
        )
    }
    guard variant.reference.sampleRate == 24_000,
          variant.reference.channels == 1,
          variant.reference.normalizedFormat == "wav_float32_le" else {
        throw TuringQwenNativeError.invalidConfig(
            "\(logPrefix) reference must be 24 kHz mono float32 WAV."
        )
    }

    let variantRoot = variantManifestURL.deletingLastPathComponent()
    let originalURL = variantRoot.appendingPathComponent(
        variant.reference.originalAudioPath
    )
    let normalizedURL = variantRoot.appendingPathComponent(
        variant.reference.normalizedAudioPath
    )
    let textURL = variantRoot.appendingPathComponent(
        variant.reference.textPath
    )

    try requireNonEmptyFile(originalURL, label: "\(logPrefix) original audio")
    try requireNonEmptyFile(normalizedURL, label: "\(logPrefix) normalized audio")
    try requireNonEmptyFile(textURL, label: "\(logPrefix) reference text")

    let artifactPaths = try resolvedArtifactPaths(
        variant: variant,
        variantRoot: variantRoot,
        logPrefix: logPrefix
    )
    try requireNonEmptyFile(
        artifactPaths.clonePromptManifestURL,
        label: "\(logPrefix) clone prompt manifest"
    )
    try requireNonEmptyFile(
        artifactPaths.referenceCodesURL,
        label: "\(logPrefix) reference codes"
    )
    try requireNonEmptyFile(
        artifactPaths.referenceTextTokensURL,
        label: "\(logPrefix) reference text tokens"
    )
    try requireNonEmptyFile(
        artifactPaths.speakerEmbeddingURL,
        label: "\(logPrefix) speaker embedding"
    )

    let referenceText = try String(contentsOf: textURL, encoding: .utf8)
        .trimmingCharacters(in: .whitespacesAndNewlines)
    guard referenceText.isEmpty == false else {
        throw TuringQwenNativeError.missingModelFile(
            "\(logPrefix) reference text is empty."
        )
    }

    let loadedVariant = TuringQwenNativeCloneProfile.Variant(
        variantID: variant.variantID,
        rootURL: variantRoot,
        manifestURL: variantManifestURL,
        originalReferenceAudioURL: originalURL,
        normalizedReferenceAudioURL: normalizedURL,
        refTextURL: textURL,
        clonePromptManifestURL: artifactPaths.clonePromptManifestURL,
        referenceCodesURL: artifactPaths.referenceCodesURL,
        referenceTextTokensURL: artifactPaths.referenceTextTokensURL,
        speakerEmbeddingURL: artifactPaths.speakerEmbeddingURL,
        sampleRate: variant.reference.sampleRate,
        channels: variant.reference.channels
    )

    print("""
    [TuringCloneProfile] profile loaded
      characterID: \(metadata.characterID)
      voiceID: \(metadata.voiceID)
      defaultVariantID: \(metadata.defaultVariantID)
      sharedModelID: \(metadata.modelID)
      fallbackAllowed: false
    """)

    return TuringQwenNativeCloneProfile(
        voiceID: metadata.voiceID,
        speakerID: metadata.characterID,
        modelID: metadata.modelID,
        profileKind: metadata.profileKind,
        rootURL: profileRoot,
        referenceAudioURL: normalizedURL,
        originalReferenceAudioURL: originalURL,
        referenceText: referenceText,
        defaultVariantID: metadata.defaultVariantID,
        allowFallback: false,
        variants: [loadedVariant.variantID: loadedVariant]
    )
}
```

Update resolvedArtifactPaths to accept logPrefix and remove the hardcoded
"Run precompute_big_mike..." error. Its failure must identify the profile and

Rich uses AVAudioPlayer as a nonspatial, completion-owned one-shot player.
There is exactly one active Rich player per playback coordinator.

TuringRichGlobalOneShotClipPlayer.swift:

```swift
import AVFoundation
import Foundation

@MainActor
final class TuringRichGlobalOneShotClipPlayer: NSObject,
    AVAudioPlayerDelegate {

    enum ClipKind: String, Sendable {
        case generated
        case filler
        case walkieOpen
        case walkieSend
        case prerecording
    }

    struct Handle: Hashable, Sendable {
        let id: UUID
    }

    enum PlayerError: LocalizedError {
        case alreadyPlaying
        case couldNotStart(String)

        var errorDescription: String? {
            switch self {
            case .alreadyPlaying:
                return "Rich global player already owns an active clip."
            case .couldNotStart(let label):
                return "Could not start Rich global clip: \(label)."
            }
        }
    }

    private struct ActiveClip {
        let handle: Handle
        let player: AVAudioPlayer
        let playerID: ObjectIdentifier
        let kind: ClipKind
        let label: String
        let fileURL: URL
        let startedAt: Date
        let completion: @MainActor (Handle, Bool) -> Void
    }

    private var active: ActiveClip?

    @discardableResult
    func play(
        fileURL: URL,
        kind: ClipKind,
        label: String,
        gainDB: Float,
        completion: @escaping @MainActor (Handle, Bool) -> Void
    ) throws -> Handle {
        guard active == nil else {
            throw PlayerError.alreadyPlaying
        }

        let player = try AVAudioPlayer(contentsOf: fileURL)
        player.numberOfLoops = 0
        player.volume = Self.linearGain(fromDB: gainDB)
        player.delegate = self
        player.prepareToPlay()

        let handle = Handle(id: UUID())
        active = ActiveClip(
            handle: handle,
            player: player,
            playerID: ObjectIdentifier(player),
            kind: kind,
            label: label,
            fileURL: fileURL,
            startedAt: Date(),
            completion: completion
        )

        guard player.play() else {
            active = nil
            throw PlayerError.couldNotStart(label)
        }

        print("""
        [TuringRichGlobalPlayer] playback started
          handleID: \(handle.id.uuidString)
          kind: \(kind.rawValue)
          label: \(label)
          file: \(fileURL.lastPathComponent)
          route: global
          spatialEmitter: none
          gainDB: \(String(format: "%.1f", gainDB))
          completionSource: AVAudioPlayerDelegate
        """)
        return handle
    }

    nonisolated func audioPlayerDidFinishPlaying(
        _ player: AVAudioPlayer,
        successfully flag: Bool
    ) {
        let playerID = ObjectIdentifier(player)
        Task { @MainActor [weak self] in
            self?.finish(playerID: playerID, successfully: flag)
        }
    }

    nonisolated func audioPlayerDecodeErrorDidOccur(
        _ player: AVAudioPlayer,
        error: Error?
    ) {
        let playerID = ObjectIdentifier(player)
        let message = error?.localizedDescription ?? "unknown decode error"
        Task { @MainActor [weak self] in
            print("""
            [TuringRichGlobalPlayer] decode error
              error: \(message)
            """)
            self?.finish(playerID: playerID, successfully: false)
        }
    }

    func cancelActive(reason: String) {
        guard let active else { return }
        self.active = nil
        active.player.stop()
        active.player.delegate = nil
        print("""
        [TuringRichGlobalPlayer] playback cancelled
          handleID: \(active.handle.id.uuidString)
          kind: \(active.kind.rawValue)
          reason: \(reason)
        """)
    }

    private func finish(
        playerID: ObjectIdentifier,
        successfully: Bool
    ) {
        guard let active,
              active.playerID == playerID else {
            print("[TuringRichGlobalPlayer] stale completion ignored")
            return
        }

        self.active = nil
        active.player.delegate = nil
        let elapsed = Date().timeIntervalSince(active.startedAt)
        print("""
        [TuringRichGlobalPlayer] playback completed
          handleID: \(active.handle.id.uuidString)
          kind: \(active.kind.rawValue)
          label: \(active.label)
          successfully: \(successfully)
          elapsedSeconds: \(String(format: "%.3f", elapsed))
          completionSource: AVAudioPlayerDelegate
        """)
        active.completion(active.handle, successfully)
    }

    private static func linearGain(fromDB db: Float) -> Float {
        min(1, max(0, pow(10, db / 20)))
    }
}
```

TuringRichFillerCatalog.swift:

```swift
import Foundation

struct TuringRichFillerCatalog: Sendable {
    private let weightedEntries: [URL]

    init(bundle: Bundle = .main) {
        weightedEntries = Self.discover(bundle: bundle)
    }

    var uniqueFileCount: Int {
        Set(weightedEntries).count
    }

    var weightedEntryCount: Int {
        weightedEntries.count
    }

    func randomURL(avoiding previous: URL?) -> URL? {
        guard weightedEntries.isEmpty == false else { return nil }
        if let previous,
           Set(weightedEntries).count > 1 {
            return weightedEntries.filter { $0 != previous }.randomElement()
        }
        return weightedEntries.randomElement()
    }

    private static func discover(bundle: Bundle) -> [URL] {
        let extensions: Set<String> = ["wav", "mp3", "m4a", "aiff", "caf"]
        var found: [URL] = []

        for candidate in TuringRichVoiceIdentity.fillerDirectoryCandidates {
            let directories = [
                bundle.resourceURL?.appendingPathComponent(candidate),
                bundle.bundleURL.appendingPathComponent(candidate)
            ].compactMap { $0 }

            for directory in directories {
                guard let files = try? FileManager.default.contentsOfDirectory(
                    at: directory,
                    includingPropertiesForKeys: nil
                ) else { continue }

                for file in files.sorted(by: { $0.path < $1.path }) {
                    guard extensions.contains(file.pathExtension.lowercased()) else {
                        continue
                    }
                    found.append(
                        contentsOf: Array(
                            repeating: file,
                            count: weight(from: file)
                        )
                    )
                }
            }
        }
        return found
    }

    private static func weight(from url: URL) -> Int {
        let stem = url.deletingPathExtension().lastPathComponent
        guard let suffix = stem.split(separator: "_").last,
              let value = Int(suffix) else {
            return 1
        }
        return max(1, min(10, value))
    }
}
```

```swift
private enum ActiveItem: Equatable {
    case none
    case walkieOpen(TuringRichGlobalOneShotClipPlayer.Handle)
    case filler(TuringRichGlobalOneShotClipPlayer.Handle, URL)
    case generated(
        segmentIndex: Int,
        handle: TuringRichGlobalOneShotClipPlayer.Handle,
        fileURL: URL
    )
    case deadAir(UUID)
    case walkieSend(TuringRichGlobalOneShotClipPlayer.Handle)
    case cancelled
}

private func reconcile(reason: String) async {
    guard runActive,
          playbackGateOpen,
          activeItem == .none else {
        return
    }

    while skippedSegments.remove(nextPlaybackSegmentIndex) != nil {
        nextPlaybackSegmentIndex += 1
    }

    // Explicit opt-in only. It runs once and is serialized by the same player.
    if outputContext == .walkieOutgoingGlobal,
       walkieOpenCompleted == false {
        await startWalkieOpen(reason: reason)
        return
    }

    // Same first-preroll convention as Big Mike, using only Rich filler.
    if firstPrerollRemaining > 0,
       pendingGenerated[nextPlaybackSegmentIndex] != nil {
        firstPrerollRemaining -= 1
        await startFiller(reason: "firstSegmentPreroll")
        return
    }

    if let clip = pendingGenerated.removeValue(
        forKey: nextPlaybackSegmentIndex
    ) {
        await startGenerated(clip, reason: reason)
        return
    }

    if generationAndPlaybackBodyFinished {
        if outputContext == .walkieOutgoingGlobal,
           walkieSendCompleted == false {
            await startWalkieSend(reason: reason)
            return
        }
        finishRun(reason: "allDone")
        return
    }

    if activeComputeSegments.isEmpty == false,
       policy.chainFillerWhileComputeWithoutSpeech {
        // Match the current Big Mike initial-preroll convention: do not burn
        // through Rich filler clips before segment zero is ready. Wait in
        // cancellable dead air, then play exactly one preroll filler once
        // segment zero exists.
        if nextPlaybackSegmentIndex == 0,
           pendingGenerated[0] == nil {
            if policy.deadAirAfterFillerEnabled {
                startDeadAir(reason: "initialGeneratedSegmentWaiting")
            }
            return
        }
        await startFillerOrDeadAir(reason: "computeWithoutSpeech")
    }
}
```

Actual completion matching is mandatory:

```swift
private func clipCompleted(
    handle: TuringRichGlobalOneShotClipPlayer.Handle,
    successfully: Bool
) async {
    switch activeItem {
    case .generated(let index, let activeHandle, let fileURL)
        where activeHandle == handle:
        activeItem = .none
        cleanupGeneratedWAV(fileURL)
        nextPlaybackSegmentIndex = index + 1
        print("""
        [TuringRichPlayback] generated playback completed
          segmentIndex: \(index)
          completionSource: AVAudioPlayerDelegate
          successfully: \(successfully)
        """)
        await reconcile(reason: "generatedCompleted")

    case .filler(let activeHandle, _)
        where activeHandle == handle:
        activeItem = .none
        if pendingGenerated[nextPlaybackSegmentIndex] == nil,
           activeComputeSegments.isEmpty == false,
           policy.deadAirAfterFillerEnabled {
            startDeadAir(reason: "afterFiller")
        } else {
            await reconcile(reason: "fillerCompleted")
        }

    case .walkieOpen(let activeHandle)
        where activeHandle == handle:
        activeItem = .none
        walkieOpenCompleted = true
        await reconcile(reason: "walkieOpenCompleted")

    case .walkieSend(let activeHandle)
        where activeHandle == handle:
        activeItem = .none
        walkieSendCompleted = true
        await reconcile(reason: "walkieSendCompleted")

    default:
        print("""
        [TuringRichPlayback] stale completion ignored
          handleID: \(handle.id.uuidString)
        """)
    }
}
```

Generated WAV handling should extract the already-proven tmp -> final -> reopen
validation logic from TuringStoryWalkiePlaybackCoordinator.writeGeneratedWAV.
The Rich version must retain these exact mechanics:

```text
samples
  -> segment_000N.tmp.wav
  -> close AVAudioFile
  -> atomic move to segment_000N.wav
  -> reopen final WAV
  -> require length > 0 and sampleRate > 0
  -> publish by segmentIndex
  -> play globally
  -> wait for AVAudioPlayerDelegate completion
  -> delete that WAV
  -> advance index
```

Dead air is the only place Task.sleep is allowed. Dead air is not audio and can
be cancelled immediately when the next generated clip becomes ready. A real
filler clip is never interrupted.

The playback gate must prevent every Rich item, including open-comm and filler,
from starting while Big Mike's incoming prerecording is still playing. Qwen may
publish completed Rich WAVs while the gate is closed.

15. PER-VOICE OUTPUT POSTPROCESSING
======================================================================

Current TuringQwenOutputPostProcessor applies a global default rate of 0.85.
Rich also requires 0.85, but character behavior must not depend on that global
default. Declare 0.85 independently for both voices and pass the selected voice
policy explicitly at the generated-audio handoff.

The intended Rich optimization is:

```text
fast Rich reference remains fast during clone conditioning
-> Qwen is encouraged to generate fewer/faster codec rows
-> generated Rich samples are pitch-preserving time-stretched at rate 0.85
-> stretched samples are written to the final playback WAV
-> global player plays the full stretched WAV to delegate completion
```

At rate 0.85, output duration is approximately 1 / 0.85 = 1.176 times the raw
Qwen duration. This time stretch cannot itself reduce Qwen compute; the compute
benefit exists only if the fast reference causes Qwen to emit fewer rows.

Add TuringQwenOutputProcessingPolicy.swift:

```swift
import Foundation
import TuringQwenNative

actor TuringRichQwenRenderer {
    private let resources = TuringBaseCloneRuntimeResources()

    func render(
        segments: [TuringSpeechSegment],
        runID: String,
        onStarted: @Sendable @escaping (Int) async -> Void,
        onFinished: @Sendable @escaping (
            Int,
            TuringComputeGapGeneratedAudio
        ) async -> Void,
        onSkipped: @Sendable @escaping (Int, String) async -> Void
    ) async throws {
        guard let bundleRoot = Bundle.main.resourceURL else {
            throw TuringRuntimeError.invalidConfig(
                "Missing app resource root for Rich clone."
            )
        }

        let profile = try TuringQwenNativeCloneProfileLoader()
            .loadRichBaseCloneProfile(from: bundleRoot)
        let bundledModel = try resources.locateBundledModel()
        let stagedModel = try resources.stageWritableModel(from: bundledModel)

        let pool = try TuringQwenNativeGenerationSchedulerFactory
            .makeFresh2Pool()

        do {
            try await pool.warmLoadExactlyRequestedInstances(
                modelRoot: stagedModel,
                cloneProfile: profile,
                variantID: profile.defaultVariantID,
                performanceMode: .performance
            )

            let scheduler = TuringQwenNativeGenerationSchedulerFactory
                .makeFresh2Scheduler(instancePool: pool)

            let requests = segments.enumerated().map { index, segment in
                TuringQwenNativeBaseCloneSegmentRequest(
                    segmentIndex: index,
                    text: segment.text,
                    language: "english",
                    cloneProfile: profile,
                    maxNewRows: 160,
                    performanceMode: .performance,
                    referenceRowLimit: 160,
                    referenceWindowStrategy: .suffix
                )
            }

            _ = try await scheduler.renderSegments(
                requests,
                runID: runID,
                skipSegmentFailures: true,
                onSegmentStarted: { _, segmentIndex in
                    await onStarted(segmentIndex)
                },
                onSegmentFinished: { result in
                    await onFinished(
                        result.segmentIndex,
                        TuringComputeGapGeneratedAudio(
                            segmentIndex: result.segmentIndex,
                            samples: result.audio.samples,
                            sampleRate: Double(result.audio.sampleRate),
                            channelCount: 1
                        )
                    )
                },
                onSegmentSkipped: { skipped in
                    await onSkipped(
                        skipped.segmentIndex,
                        skipped.errorDescription
                    )
                }
            )

            await pool.unloadAll(reason: "richFinished.\(runID)")
        } catch {
            await pool.unloadAll(reason: "richFailed.\(runID)")
            throw error
        }
    }
}
```

The maxNewRows/referenceRowLimit values above match the current production-style
voicePrompt path. They remain emergency/reference bounds, not audio-duration
estimates and not playback completion signals.

Do not keep a warmed Big Mike pool and Rich pool resident together for this MVP.

There is no Rich ambient static loop in this MVP.

Replace the debug button's runner call:

The button label can remain a clear test label such as:

Do not call radioStaticLeadIn.start around the Rich output. Incoming Big Mike

18. DEFAULT ROOM-OBJECT VOICEPROMPT FLOW
======================================================================

Every object-triggered Rich voicePrompt uses the same Foundation service and
Rich renderer, but outputContext defaults to roomGlobal:

```text
room object trigger
-> load TuringVoicePromptTriggerDescriptor
-> require speakerID=rich and voiceID=rich_base_clone_v1
-> Foundation generateVoicePrompt with rich.json
-> Rich Fresh2 Qwen rendering
-> Rich global playback coordinator
-> Rich filler/generated speech globally
-> no open-comm
-> no send-comm
-> no static
-> no walkie emitter
```

Make the default explicit in the convenience API:

```swift
static func runObjectVoicePrompt(
    descriptorID: String,
    outputContext: TuringRichOutputContext = .roomGlobal
) async -> TuringNativeQwenRunResult
```

The descriptor's context should normally be honored. The convenience default
exists so new object code cannot accidentally opt into walkie behavior.

21. ACCEPTANCE TESTS
======================================================================

A. Clone artifact validation

  - Rich metadata voiceID is rich_base_clone_v1.
  - Rich characterID is rich.
  - Default variant exists.
  - Reference is 24 kHz mono float32 WAV.
  - ref_text is nonempty and exact.
  - All precomputed artifacts are nonempty.
  - No fallback flags are true.

B. Identity isolation

  - Rich request loads only Rich clone artifacts.
  - Big Mike request still loads only Big Mike clone artifacts.
  - Rich and Big Mike cache/run keys cannot collide.
  - No global activeVoiceID switch is required.

C. Filler convention

  - Missing suffix has weight 1.
  - _0 clamps to 1.
  - _6 yields six weighted entries.
  - _99 clamps to 10.
  - Immediate repeat is avoided when at least two unique files exist.
  - Rich never falls back to a Big Mike filler file.

D. Global route

  - Rich generated speech is audible without a walkie entity installed.
  - Rich generated/filler/open/send create no RealityKit entities.
  - All Rich logs say route global and spatialEmitter none.

E. Default object route

  - roomGlobal is the default.
  - No open-comm is played.
  - No send-comm is played.
  - No static or random burst starts.

F. Explicit walkie route

  - Exactly one open-comm plays before the first Rich filler/speech.
  - Exactly one send-comm plays after the last Rich generated clip.
  - Both SFX are global.
  - No ambient/sending static is inherited.

G. Incoming/outgoing sequencing

  - Foundation and Rich Qwen can compute while Big Mike PR plays.
  - Rich output remains silent while playback gate is closed.
  - Rich open-comm cannot start before Big Mike actual completion.
  - Rich does not overlap the Big Mike prerecording.

H. Generated ordering

  - Segment 1 may finish Qwen before segment 0.
  - Playback still starts 0, then 1, then 2.
  - Segment N+1 cannot start before segment N's AVAudioPlayer delegate callback.
  - A stale callback cannot advance the cursor.
  - Generated WAV cleanup occurs after completion only.

I. Fresh2

  - Exactly two fresh instances warm-load with Rich profile.
  - Both can render concurrently.
  - Ordered playback remains independent of completion order.
  - Both unload after generation.
  - No shared-lane/single-instance fallback is used.

J. Postprocess isolation

  - Big Mike continues to log rate 0.850.
  - Rich logs voiceID rich_base_clone_v1 and rate 0.850 applied.
  - Rich generated WAV frame count reflects the stretched sample count.
  - The global player waits for completion of the full stretched Rich WAV.
  - Changing Rich's rate later does not change Big Mike, despite both starting
    at the same numerical value.

K. Failure behavior

  - Rich Foundation failure does not stop Big Mike PR playback.
  - One skipped Rich Qwen segment advances only that segment.
  - Missing Rich filler results in silence, not Big Mike filler.
  - Missing open/send in walkie mode reports a clear Rich envelope failure.
  - No fallback voice is invoked.

L. System video recording

  - Start system recording before the test.
  - Play Big Mike PR, Rich open, Rich filler, Rich speech, Rich send.
  - Recording remains active.
  - Static search confirms no new setCategory/setMode/setActive calls.

24. FINAL ARCHITECT SUMMARY
======================================================================

Rich is not a Big Mike variant. Rich is a separate speaker family that shares
only character-neutral Qwen model/runtime primitives.

The default path is:

  Rich voicePrompt
  -> rich.json
  -> rich_base_clone_v1
  -> exactly two fresh Qwen instances
  -> Rich global ordered playback
  -> no walkie effects
  -> no spatial emitter

The first explicit walkie test is:

  Big Mike PR spatial at walkie
  + Rich Foundation/Qwen compute-ahead
  -> wait for incoming actual completion
  -> global open-comm
  -> global Rich filler/generated clips in order
  -> global send-comm

The route distinction is semantic and structural, not a gain or position flag:

  Big Mike = remote character, spatial at walkie
  Rich = player character, global/nonspatial everywhere

Keep those ownership boundaries intact as object-triggered Rich voicePrompts are
added later.
