TURING STORY PLACEMENT ADJUSTMENT BARS
ARCHITECT IMPLEMENTATION HANDOFF

PURPOSE

Add a lightweight manual art-direction pass after the Story room scan and
Foundation wall layout commit.

The user must be able to move the door, window, walkie shelf, and poster through
cached room-scan placements without rescanning and without unconstrained world
dragging.

Required flow:

room scan
-> code generates the full placement catalog and spin-ordered slices
-> Foundation selects the initial layout
-> initial layout commits
-> four adjustment bars appear
-> pinch one bar
-> drag left/right through a circular ordered route of cached positions
-> preview the selected position
-> release to update that prop's occupancy and commit

NON-NEGOTIABLE BEHAVIOR

1. One coordinator owns adjustment for all props.
2. Only one prop can be adjusted at a time.
3. Dragging never creates arbitrary world coordinates.
4. Preview choices come from the frozen scan candidate cache.
5. Other three props remain fixed and occupied while one prop moves.
6. Illegal alternatives are removed before interaction, not rejected after preview.
7. Preview does not mutate occupancy.
8. Release commits occupancy exactly once.
9. Cancel restores the original transform and occupancy.
10. Candidate order follows the captured spin order and wraps around the room.
11. The feature does not rerun Foundation and does not rescan the room.
12. Do not create four independent drag controllers.

```swift
import simd

enum TuringStoryRuntimePlacement: Sendable {
    case door(TuringStoryDoorBundlePlacement)
    case window(TuringStoryWindowBundlePlacement)
    case walkieShelf(TuringStoryWallBundlePlacement)

    let slotID: String
    let propID: TuringStoryPropID
    let wallID: UUID
    let wallOrdinal: Int
    let sliceIDs: [String]
    let routeOrder: Float
    let worldTransform: simd_float4x4
    let semanticReservation: WallLocalRect
    let score: Float

}

struct TuringStoryPlacementAdjustmentSeed: Sendable {
    let scanID: String
    let candidatesByProp: [TuringStoryPropID: [TuringStoryRuntimeSlot]]
    let initiallySelectedSlotIDByProp: [TuringStoryPropID: String]

```

Add Sendable to the existing poster placement value in
WallMountedPosterUIModels.swift so TuringStoryRuntimePlacement can remain Sendable:

```swift
struct WallPosterPlacement: Sendable {
    var wallID: UUID
    var localX: Float
    var localY: Float
    var depthOffset: Float
    var width: Float
    var height: Float

```

Why the typed placement enum is required:

- Door and window grounding use controller-specific floor-relative math.
- Walkie shelf and poster use different placement structures.
- Preview and commit must use the exact transform that the relevant controller uses.
- Do not reconstruct controller placement from a generic transform on release.

CANDIDATE CACHE

Create TuringStoryPlacementCandidateCache.swift.

The cache is built from:

- TuringStoryExactPlacementCatalog
- TuringStoryWallSliceMap
- the final TuringStoryResolvedSliceLayout
- current WallPlaneManager candidates
- prepared prop controllers, so their actual grounded transforms are available

Do not serialize this cache to Foundation. It is runtime-only.

```swift
import Foundation

struct TuringStoryPlacementCandidateCache: Sendable {
    private(set) var slotsByProp: [TuringStoryPropID: [TuringStoryRuntimeSlot]]

    func slots(for propID: TuringStoryPropID) -> [TuringStoryRuntimeSlot] {
        slotsByProp[propID] ?? []
    }

    func slot(propID: TuringStoryPropID, slotID: String) -> TuringStoryRuntimeSlot? {
        slotsByProp[propID]?.first { $0.slotID == slotID }
    }
}
```

Candidate materialization rules:

1. Start from every TuringStoryExactPlacement for each prop.
2. Find all spin-order slices horizontally covered by exact.runtimeSemanticRect.
3. Use the first covered slice as the route anchor.
4. Preserve all covered slice IDs in slot.sliceIDs.
5. Materialize the controller-specific placement and actual world transform.
6. Sort by wallOrdinal, then by the direction of slices on that wall.
7. Keep the final route circular.
8. If the initial Foundation selection was produced by direct slice projection and
   is not present in the exact catalog, insert that resolved slot as the active
   current slot. Do not silently move the initial layout when bars appear.

Route ordering code shape:

```swift
private func routeOrder(
    exact: TuringStoryExactPlacement,
    anchorSlice: TuringStoryWallSlice,
    wall: TuringStorySpinOrderedWall
) -> Float {
    let startX = localX(worldXZ: wall.startXZ, wall: wall.runtimeWall)
    let endX = localX(worldXZ: wall.endXZ, wall: wall.runtimeWall)
    let denominator = max(0.001, abs(endX - startX))
    let progress = max(0, min(1, abs(exact.localX - startX) / denominator))
    return Float(wall.wallOrdinal) + progress
}
```

Do not use lexical slotID sorting. Route order is measured spin order.

PLACEMENT CONTROLLER INTERFACE

Add one shared protocol. The four existing controllers implement it; they do not

```swift
@MainActor
protocol TuringStoryAdjustablePlacementController: AnyObject {
```

Each controller must retain the last committed transform separately from the
preview transform:

```swift
private var committedAdjustmentTransform: simd_float4x4?

func previewPlannedPlacement(
    _ slot: TuringStoryRuntimeSlot,
    duration: TimeInterval
) {
    adjustmentRoot.move(
        to: Transform(matrix: slot.worldTransform),
        relativeTo: nil,
        duration: duration,
        timingFunction: .easeInOut
    )
}

func cancelPlacementPreview() {
    guard let committedAdjustmentTransform else { return }
    adjustmentRoot.move(
        to: Transform(matrix: committedAdjustmentTransform),
        relativeTo: nil,
        duration: 0.18,
        timingFunction: .easeInOut
    )
}
```

Commit must be lightweight. Do not reload USDZ assets, rebuild portal worlds,
reinstall icons, or rebind materials during adjustment commit.

Door commit shape:

```swift
func commitAdjustedPlacement(_ slot: TuringStoryRuntimeSlot) throws {
    guard case .door(let adjusted) = slot.placement else {
        throw TuringStoryPlacementAdjustmentError.wrongPlacementType
    }
    root.setTransformMatrix(slot.worldTransform, relativeTo: nil)
    placement = adjusted
    isPlaced = true
    committedAdjustmentTransform = slot.worldTransform
    registerOccupancy(
        placement: adjusted,
        semanticReservation: slot.semanticReservation
    )
}
```

Window, walkie shelf, and poster use the same pattern with their typed payload.
The existing portal world, audio emitter, door animation controller, icon, glass,
and authored children move because they are children of the prop root.

Poster requires new adjustment-specific methods because current
commitPlannedStoryPlacement(...) requires placementState == .notPlaced.
Do not reset and rebuild the poster just to move it.

Poster commit shape:

```swift
func commitAdjustedPlacement(_ slot: TuringStoryRuntimeSlot) throws {
    guard case .poster(let adjusted) = slot.placement,
          let transform = worldTransform(for: adjusted) else {
        throw TuringStoryPlacementAdjustmentError.wrongPlacementType
    }
    root.setTransformMatrix(transform, relativeTo: nil)
    currentPlacement = adjusted
    committedPlacement = CommittedWallPosterPlacement(
        candidatePlacement: adjusted,
        worldTransform: transform,
        occupancyID: posterOccupancyID
    )
    placementState = .locked
    _ = registerPosterOccupancy(
        placement: adjusted,
        semanticReservation: slot.semanticReservation
    )
    committedAdjustmentTransform = transform
}
```

Selectable route construction:

```swift
private func selectableRoute(
    propID: TuringStoryPropID,
    adapter: any TuringStoryAdjustablePlacementController
) -> [TuringStoryRuntimeSlot] {
    cache.slots(for: propID).filter { slot in
        !occupancyRegistry.hasHardOverlap(
            wallID: slot.wallID,
            candidate: slot.semanticReservation,
            candidateKind: propID.occupancyKind,
            ignoredIDs: [adapter.adjustmentOccupancyID],
            emitDiagnostics: false
        )
    }
}
```

height, and fixed-occupancy construction. Do not rerun those calculations in the
gesture loop. Only current live occupancy filtering belongs in the loop.

ONE ADJUSTMENT COORDINATOR

Create TuringStoryPlacementAdjustmentCoordinator.swift.

```swift
import Foundation
import RealityKit
import simd

@MainActor
final class TuringStoryPlacementAdjustmentCoordinator {
    private enum Tuning {
        static let candidateStepMeters: Float = 0.065
        static let hysteresisMeters: Float = 0.016
        static let snapDurationSeconds: TimeInterval = 0.20
    }

    private struct ActiveDrag {
        let propID: TuringStoryPropID
        let originalSlot: TuringStoryRuntimeSlot
        var route: [TuringStoryRuntimeSlot]
        var index: Int
        var lastWorldPoint: SIMD3<Float>
        let dragAxis: SIMD3<Float>
        var accumulatedMeters: Float
    }

    private let occupancyRegistry: WallPropOccupancyRegistry
    private let adapters: [
        TuringStoryPropID: any TuringStoryAdjustablePlacementController
    ]
    private let bars = TuringStoryPlacementAdjustmentBarPresenter()

    private var cache = TuringStoryPlacementCandidateCache(slotsByProp: [:])
    private var activeSlotByProp: [TuringStoryPropID: TuringStoryRuntimeSlot] = [:]
    private var activeDrag: ActiveDrag?

    init(
        occupancyRegistry: WallPropOccupancyRegistry,
        adapters: [TuringStoryPropID: any TuringStoryAdjustablePlacementController]
    ) {
        self.occupancyRegistry = occupancyRegistry
        self.adapters = adapters
    }

    func install(sceneRoot: Entity) {
        bars.install(sceneRoot: sceneRoot)
    }

    func activate(seed: TuringStoryPlacementAdjustmentSeed) {
        cancel(reason: "newPlacementSeed")
        cache = TuringStoryPlacementCandidateCache(
            slotsByProp: seed.candidatesByProp
        )
        let activePairs: [(TuringStoryPropID, TuringStoryRuntimeSlot)] =
            seed.initiallySelectedSlotIDByProp.compactMap { entry in
                let (propID, slotID) = entry
                return cache.slot(propID: propID, slotID: slotID).map {
                    (propID, $0)
                }
            }
        activeSlotByProp = Dictionary(uniqueKeysWithValues: activePairs)
        bars.show(activeSlots: activeSlotByProp)
    }

    func begin(
        propID: TuringStoryPropID,
        worldPoint: SIMD3<Float>
    ) {
        guard activeDrag == nil,
              let adapter = adapters[propID],
              let current = activeSlotByProp[propID] else { return }

        var route = selectableRoute(propID: propID, adapter: adapter)
        if !route.contains(where: { $0.slotID == current.slotID }) {
            route.append(current)
            route.sort { $0.routeOrder < $1.routeOrder }
        }
        guard let index = route.firstIndex(where: { $0.slotID == current.slotID }) else {
            return
        }

        activeDrag = ActiveDrag(
            propID: propID,
            originalSlot: current,
            route: route,
            index: index,
            lastWorldPoint: worldPoint,
            dragAxis: bars.worldRightAxis(for: propID),
            accumulatedMeters: 0
        )
        bars.setVisualState(.pinched, propID: propID)
    }

    func update(worldPoint: SIMD3<Float>) {
        guard var drag = activeDrag else { return }
        let delta = worldPoint - drag.lastWorldPoint
        drag.lastWorldPoint = worldPoint
        drag.accumulatedMeters += simd_dot(delta, drag.dragAxis)

        if drag.accumulatedMeters >= Tuning.candidateStepMeters {
            step(direction: 1, drag: &drag)
            drag.accumulatedMeters = -Tuning.hysteresisMeters
        } else if drag.accumulatedMeters <= -Tuning.candidateStepMeters {
            step(direction: -1, drag: &drag)
            drag.accumulatedMeters = Tuning.hysteresisMeters
        }
        activeDrag = drag
    }

    private func step(direction: Int, drag: inout ActiveDrag) {
        guard !drag.route.isEmpty,
              let adapter = adapters[drag.propID] else { return }
        drag.index = (drag.index + direction + drag.route.count) % drag.route.count
        let slot = drag.route[drag.index]
        adapter.previewPlannedPlacement(
            slot,
            duration: Tuning.snapDurationSeconds
        )
        bars.preview(slot: slot, duration: Tuning.snapDurationSeconds)
        bars.setVisualState(.snapping, propID: drag.propID)
    }

    func end(commit: Bool) {
        guard let drag = activeDrag,
              let adapter = adapters[drag.propID] else { return }
        defer {
            activeDrag = nil
            bars.setVisualState(.idle, propID: drag.propID)
        }

        guard commit else {
            adapter.cancelPlacementPreview()
            bars.preview(slot: drag.originalSlot, duration: 0.18)
            return
        }

        let selected = drag.route[drag.index]
        do {
            try adapter.commitAdjustedPlacement(selected)
            activeSlotByProp[drag.propID] = selected
            bars.commit(slot: selected)
            refilterAllRoutesAfterCommit()
        } catch {
            adapter.cancelPlacementPreview()
            bars.preview(slot: drag.originalSlot, duration: 0.18)
            print("[TuringPlacementAdjust] commit failed prop=\(drag.propID.rawValue) error=\(error.localizedDescription)")
        }
    }

    func cancel(reason: String) {
        if let drag = activeDrag {
            adapters[drag.propID]?.cancelPlacementPreview()
        }
        activeDrag = nil
        bars.hideAll(reason: reason)
    }
}
```

The coordinator must not call Foundation, scan APIs, or independent choosePlacement
methods.

BAR POSITIONING

Bars must face outward using the same wall right/up/normal basis as the selected
slot. Place the bar approximately 0.02 meters farther from the wall than the prop.

Vertical positions:

door: floorWorldY + 0.12 m
window: visual bottom - 0.06 m
walkie shelf: visual bottom - 0.06 m
poster: visual bottom - 0.06 m

Clamp only the bar visual above the detected floor. Do not change the prop slot.

The bar presenter should calculate a world transform from the slot and current
WallCandidate. Do not author adjustment anchors into the USDZ files.

PLAGUE IMMERSIVE VIEW GESTURE

Add one targeted gesture beside the existing portal handle, poster, door icon, and
walkie mic gestures in PlagueImmersiveView.swift:

```swift
@State private var placementAdjustmentDragActive = false

.simultaneousGesture(
    DragGesture(minimumDistance: 0)
        .targetedToEntity(
            where: .has(TuringStoryPlacementAdjustmentBarComponent.self)
        )
        .onChanged { value in
            guard let component = value.entity.components[
                TuringStoryPlacementAdjustmentBarComponent.self
            ] else { return }

            let point = value.convert(
                value.location3D,
                from: .local,
                to: .scene
            )
            let worldPoint = SIMD3<Float>(
                Float(point.x), Float(point.y), Float(point.z)
            )

            if placementAdjustmentDragActive {
                coordinator.updateTuringPlacementAdjustment(
                    worldPoint: worldPoint
                )
            } else {
                placementAdjustmentDragActive = true
                coordinator.beginTuringPlacementAdjustment(
                    propID: component.propID,
                    worldPoint: worldPoint
                )
            }
        }
        .onEnded { _ in
            guard placementAdjustmentDragActive else { return }
            placementAdjustmentDragActive = false
            coordinator.endTuringPlacementAdjustment(commit: true)
        }
)
```

LIFECYCLE

- a new debug room rescan
- Story placement reset
- immersive shutdown
- failed atomic initial commit
- user quit

```swift

turingStoryPlacementAdjustmentCoordinator.cancel(reason: "immersiveShutdown")
```

OUT OF SCOPE

Do not modify:

- Foundation wall-layout prompt behavior
- Qwen or TTS
- playback, filler, static, or audio session policy
- dictation HUD
- USDZ entity naming
- portal world content
- day/night switching
- door open/close animation
- prop scales
- floor heights
- Horde portal placement

DONE CRITERIA

The feature is complete only when the user can perform a final room-layout pass by
dragging faint bars through cached, occupancy-filtered, spin-ordered positions, and
each release commits exactly one prop without rescanning, rerunning Foundation, or
allowing unconstrained placement.
