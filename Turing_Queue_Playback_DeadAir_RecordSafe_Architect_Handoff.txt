Turing Queue Playback, Dead-Air Filler, And Recording-Safe Audio Handoff
======================================================================

Date: 2026-07-06
Repo: /Users/richardfallat/Projects/dev/gravitas-plague

Purpose
-------

Replace the fragile current Turing playback path with a queue-based playback
coordinator that:

1. Plays generated TTS returns sequentially in segment-index order.
2. Never replaces, interrupts, skips, or overwrites currently playing TTS.
3. Supports the requested dead-air filler policy exactly.
4. Preserves system recording / screen capture / dictation audio session state.

This handoff is not a Qwen generation change. Do not change Qwen, prompts,
models, segmentation, filler assets, or voice profiles as part of this patch.


1. Failure Analysis: What Went Wrong
------------------------------------

The current disease is playback-state conflation.

The runtime has several independent concepts mixed together:

    - Qwen compute lifecycle
    - ordered generated-speech playback
    - normal filler clips
    - static loop
    - dead-air gap timing
    - AVAudioSession recording/playback ownership
    - RealityKit entity/controller lifetime

This made the playback path fragile in several ways:

    A. The coordinator state is not a true playback queue.

       It stores pending generated segments, but real playback is still
       driven by ad-hoc calls such as reconcile(), filler completion callbacks,
       sleep-based waiters, and sink-specific completion polling.

       That makes it easy for a later event to trigger a start/stop path at
       the wrong time.

    B. Generated TTS, filler, and static were routed through the same walkie
       emitter path.

       If RealityKit treats repeated playAudio calls on the same entity as
       replacement, or if the app cleanup prunes active controllers by time,
       then filler/static/later speech can cut off currently playing speech.

    C. Playback completion was inferred rather than owned by one queue.

       Current code often estimates duration, sleeps or polls, and then calls
       realSpeechFinished(). That is acceptable only if the queue is the only
       owner allowed to advance playback. If any other path can stop or replace
       controllers, duration estimates become lies.

    D. The audio-session fix was put in the wrong layer.

       TuringComputeGapAudioCoordinator.configureAudioSessionIfAvailable()
       was changed to preserve recording or set .ambient. That was trying to
       solve recording stomp from inside the playback scheduler.

       Audio session ownership should be centralized. The playback coordinator
       should not repeatedly set AVAudioSession category while dictation,
       screen recording, or capture may be active.

    E. Dead air was added as another playback-adjacent state instead of a
       strict timer-only gap.

       Dead air must not be an audio resource, must not play through the
       walkie, and must not stop any active audio controller. It is just an
       interruptible timer between filler and next speech.

Correct disease name:

    The Turing audio pipeline lacks a single ordered playback-state owner.

Correct architectural cure:

    Introduce one queue owner that owns segment order and current playback.
    Treat filler/static/dead-air as separate side lanes with strict rules.
    Make AVAudioSession ownership central and recording-aware.


2. Target Behavior
------------------

Generated TTS:

    - Each Qwen result has a segmentIndex and samples.
    - Results may finish out of order.
    - Completed results are stored in pendingGenerated[segmentIndex].
    - Only nextPlaybackSegmentIndex may start.
    - If segment 3 is playing, segment 4 cannot start until segment 3 is done.
    - If segment 5 finishes before segment 4, it waits.
    - Never stop currently playing generated speech to play another segment.
    - Never call stopAll when a segment becomes ready.
    - Never replace an active generated playback controller.

Normal filler:

    - Normal filler clips are non-interruptible.
    - If real speech becomes ready while a filler clip plays, wait for the
      filler clip to finish.
    - Filler clips play only when no real speech is playing and the next
      required real segment is not ready.

Dead air:

    - After a normal filler clip finishes, if the next real segment is still
      not ready, start a random silent gap from 0.5 to 4.0 seconds.
    - Dead air is not audio.
    - Dead air is just a cancellable Task sleep.
    - If the next real segment becomes ready during dead air, cancel the dead
      air immediately and start the real segment.
    - Dead air cannot overlap with real speech.
    - Dead air cannot call stopAll, stopFiller, stopRadioStaticLoop, or stop
      on any AudioPlaybackController.

Static:

    - Static may play during lead-in / compute wait as requested by Story mode.
    - Static is independent from generated TTS and filler.
    - Static must not stop or replace generated TTS.
    - Static should be on its own walkie static lane.

Recording / capture:

    - Playback must not disable system recording, screen recording, or
      dictation.
    - Playback helpers must not own AVAudioSession category.
    - One centralized audio-session coordinator handles recording/playback
      requests and chooses a recording-safe category when recording is active.

```swift
import AVFoundation
import Foundation

@MainActor
final class TuringAudioSessionCoordinator {
    static let shared = TuringAudioSessionCoordinator()

    private var recordingOwners = Set<String>()
    private var playbackOwners = Set<String>()

    private init() {}

    func configureForLaunch() {
        configure(reason: "launch")
    }

    func beginRecording(owner: String) {
        recordingOwners.insert(owner)
        configure(reason: "beginRecording.\(owner)")
    }

    func endRecording(owner: String) {
        recordingOwners.remove(owner)
        configure(reason: "endRecording.\(owner)")
    }

    func beginPlayback(owner: String) {
        playbackOwners.insert(owner)
        configure(reason: "beginPlayback.\(owner)")
    }

    func endPlayback(owner: String) {
        playbackOwners.remove(owner)
        configure(reason: "endPlayback.\(owner)")
    }

    private func configure(reason: String) {
        #if os(iOS) || os(tvOS) || os(visionOS)
        let session = AVAudioSession.sharedInstance()

        do {
            if recordingOwners.isEmpty == false {
                try session.setCategory(
                    .playAndRecord,
                    mode: .default,
                    options: [
                        .mixWithOthers,
                        .allowBluetooth,
                        .defaultToSpeaker
                    ]
                )
                try session.setActive(true)
                print("""
                [TuringAudioSession] configured
                  reason: \(reason)
                  category: playAndRecord
                  mode: default
                  recordingOwners: \(recordingOwners.sorted().joined(separator: ","))
                  playbackOwners: \(playbackOwners.sorted().joined(separator: ","))
                """)
                return
            }

            try session.setCategory(
                .ambient,
                mode: .default,
                options: [
                    .mixWithOthers
                ]
            )
            try session.setActive(true)

            print("""
            [TuringAudioSession] configured
              reason: \(reason)
              category: ambient
              mode: default
              recordingOwners: none
              playbackOwners: \(playbackOwners.sorted().joined(separator: ","))
            """)
        } catch {
            print("""
            [TuringAudioSession] configure failed
              reason: \(reason)
              error: \(error.localizedDescription)
            """)
        }
        #endif
    }
}
```

4. New Playback Sink Protocol
-----------------------------

The queue needs a sink that can play generated speech and filler on separate
lanes. It should not expose stopAll as a normal ready/advance operation.

Create or replace the current sink protocol with this shape:

```swift
import Foundation

@MainActor
protocol TuringQueuedPlaybackSink: AnyObject {
    func beginRun(
        runID: String,
        expectedSegmentCount: Int?
    ) async

    func playGeneratedSegment(
        _ audio: TuringComputeGapGeneratedAudio
    ) async throws -> TuringPlaybackHandle

    func playFillerClip(
        fileURL: URL,
        label: String
    ) async throws -> TuringPlaybackHandle

    func startStaticLoop(
        fileURL: URL,
        reason: String
    ) async throws

    func stopStaticLoop(reason: String) async

    func cancelRun(reason: String) async
}

struct TuringPlaybackHandle: Sendable {
    let id: UUID
    let label: String
    let duration: TimeInterval

    init(
        id: UUID = UUID(),
        label: String,
        duration: TimeInterval
    ) {
        self.id = id
        self.label = label
        self.duration = duration
    }
}
```

Important:

    The queue, not the sink, decides when a generated segment is finished.
    The sink starts audio and returns a handle/duration. It must not advance
    queue state.


5. New Queue Coordinator
------------------------

Create:

    Gravitas Plague/Gravitas Plague/Turing/Audio/TuringGeneratedSpeechQueueCoordinator.swift

This replaces the fragile parts of TuringComputeGapAudioCoordinator for
generated speech ordering.

Code:

```swift
import AVFoundation
import Foundation

@MainActor
final class TuringGeneratedSpeechQueueCoordinator {
    struct Policy: Sendable {
        var firstSegmentPrerollFillerCount: Int
        var minimumFillerClipsBetweenSegments: Int
        var chainFillerWhileComputeWithoutSpeech: Bool
        var deadAirAfterFillerEnabled: Bool
        var deadAirMinSeconds: Double
        var deadAirMaxSeconds: Double
        var fillerDirectoryCandidates: [String]
        var fillerExtensions: Set<String>
        var avoidImmediateFillerRepeat: Bool

        static let bigMikeDefault = Policy(
            firstSegmentPrerollFillerCount: 1,
            minimumFillerClipsBetweenSegments: 0,
            chainFillerWhileComputeWithoutSpeech: true,
            deadAirAfterFillerEnabled: true,
            deadAirMinSeconds: 0.5,
            deadAirMaxSeconds: 4.0,
            fillerDirectoryCandidates: [
                "Turing/Audio/big-mike-filler",
                "Turing/big-mike-filler",
                "big-mike-filler"
            ],
            fillerExtensions: ["wav", "mp3", "m4a", "aiff", "caf"],
            avoidImmediateFillerRepeat: true
        )
    }

    private enum PlaybackState: Equatable {
        case idle
        case playingGenerated(segmentIndex: Int, handleID: UUID)
        case playingFiller(handleID: UUID)
        case deadAir
        case cancelled
    }

    private let sink: TuringQueuedPlaybackSink
    private let policy: Policy

    private var runID: String?
    private var expectedSegmentCount: Int?
    private var allComputeFinished = false
    private var runActive = false

    private var nextPlaybackSegmentIndex = 0
    private var pendingGenerated: [Int: TuringComputeGapGeneratedAudio] = [:]
    private var skippedSegments = Set<Int>()
    private var activeComputeSegments = Set<Int>()

    private var state: PlaybackState = .idle
    private var generatedFinishTask: Task<Void, Never>?
    private var fillerFinishTask: Task<Void, Never>?
    private var deadAirTask: Task<Void, Never>?

    private var fillerFiles: [URL] = []
    private var fillerQueue: [URL] = []
    private var lastFillerFile: URL?
    private var firstSegmentPrerollRemaining: Int
    private var interSegmentFillerRemaining = 0

    init(
        sink: TuringQueuedPlaybackSink,
        policy: Policy = .bigMikeDefault
    ) {
        self.sink = sink
        self.policy = policy
        self.firstSegmentPrerollRemaining = policy.firstSegmentPrerollFillerCount
        self.fillerFiles = Self.discoverFillerFiles(
            candidates: policy.fillerDirectoryCandidates,
            allowedExtensions: policy.fillerExtensions
        )
    }

    func beginRun(
        runID: String,
        expectedSegmentCount: Int?
    ) async {
        cancelTasks()

        self.runID = runID
        self.expectedSegmentCount = expectedSegmentCount
        self.allComputeFinished = false
        self.runActive = true
        self.nextPlaybackSegmentIndex = 0
        self.pendingGenerated.removeAll(keepingCapacity: true)
        self.skippedSegments.removeAll(keepingCapacity: true)
        self.activeComputeSegments.removeAll(keepingCapacity: true)
        self.state = .idle
        self.firstSegmentPrerollRemaining = policy.firstSegmentPrerollFillerCount
        self.interSegmentFillerRemaining = 0

        TuringAudioSessionCoordinator.shared.beginPlayback(
            owner: "TuringGeneratedSpeechQueue"
        )
        await sink.beginRun(
            runID: runID,
            expectedSegmentCount: expectedSegmentCount
        )

        print("""
        [TuringPlaybackQueue] run started
          runID: \(runID)
          expectedSegmentCount: \(expectedSegmentCount.map(String.init) ?? "streaming")
          firstSegmentPrerollFillerCount: \(policy.firstSegmentPrerollFillerCount)
          minimumFillerClipsBetweenSegments: \(policy.minimumFillerClipsBetweenSegments)
          deadAirAfterFiller: \(policy.deadAirAfterFillerEnabled)
          deadAirSeconds: \(String(format: "%.2f", policy.deadAirMinSeconds))...\(String(format: "%.2f", policy.deadAirMaxSeconds))
        """)

        await reconcile(reason: "runStarted")
    }

    func qwenComputeStarted(segmentIndex: Int) async {
        guard runActive else { return }
        activeComputeSegments.insert(segmentIndex)
        print("""
        [TuringPlaybackQueue] compute started
          segmentIndex: \(segmentIndex)
          nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex)
          state: \(stateLogName)
        """)
        await reconcile(reason: "computeStarted")
    }

    func qwenComputeFinished(
        segmentIndex: Int,
        audio: TuringComputeGapGeneratedAudio
    ) async {
        guard runActive else { return }
        activeComputeSegments.remove(segmentIndex)

        guard segmentIndex >= nextPlaybackSegmentIndex else {
            print("""
            [TuringPlaybackQueue] stale generated segment ignored
              segmentIndex: \(segmentIndex)
              nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex)
            """)
            return
        }

        if pendingGenerated[segmentIndex] == nil {
            pendingGenerated[segmentIndex] = audio
        }

        print("""
        [TuringPlaybackQueue] compute finished
          segmentIndex: \(segmentIndex)
          pendingIndexes: \(pendingIndexesLog)
          nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex)
          state: \(stateLogName)
        """)

        await reconcile(reason: "computeFinished")
    }

    func qwenComputeSkipped(
        segmentIndex: Int,
        reason: String
    ) async {
        guard runActive else { return }
        activeComputeSegments.remove(segmentIndex)
        skippedSegments.insert(segmentIndex)

        print("""
        [TuringPlaybackQueue] compute skipped
          segmentIndex: \(segmentIndex)
          reason: \(reason)
        """)

        await reconcile(reason: "computeSkipped")
    }

    func qwenComputeAllFinished() async {
        allComputeFinished = true
        print("[TuringPlaybackQueue] compute all finished")
        await reconcile(reason: "computeAllFinished")
    }

    func cancel(reason: String) async {
        guard runActive else { return }
        runActive = false
        state = .cancelled
        cancelTasks()
        pendingGenerated.removeAll(keepingCapacity: false)
        skippedSegments.removeAll(keepingCapacity: false)
        activeComputeSegments.removeAll(keepingCapacity: false)
        await sink.cancelRun(reason: reason)
        TuringAudioSessionCoordinator.shared.endPlayback(
            owner: "TuringGeneratedSpeechQueue"
        )
        print("""
        [TuringPlaybackQueue] run cancelled
          reason: \(reason)
        """)
    }

    private func reconcile(reason: String) async {
        guard runActive else { return }

        while skippedSegments.remove(nextPlaybackSegmentIndex) != nil {
            print("""
            [TuringPlaybackQueue] skipped segment advanced cursor
              skippedSegmentIndex: \(nextPlaybackSegmentIndex)
              nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex + 1)
            """)
            nextPlaybackSegmentIndex += 1
        }

        switch state {
        case .playingGenerated:
            return

        case .playingFiller:
            return

        case .deadAir:
            if pendingGenerated[nextPlaybackSegmentIndex] != nil {
                stopDeadAir(reason: "nextGeneratedReady")
            } else {
                return
            }

        case .cancelled:
            return

        case .idle:
            break
        }

        if shouldPlayFirstPrerollFiller {
            firstSegmentPrerollRemaining -= 1
            await startFiller(reason: "firstSegmentPreroll")
            return
        }

        if shouldPlayInterSegmentFiller {
            interSegmentFillerRemaining -= 1
            await startFiller(reason: "interSegmentBuffer")
            return
        }

        if let audio = pendingGenerated.removeValue(forKey: nextPlaybackSegmentIndex) {
            await startGenerated(audio, reason: reason)
            return
        }

        if shouldPlayComputeGapFiller {
            await startFiller(reason: "computeWithoutSpeech")
            return
        }

        if isFinished {
            await finishRun()
        }
    }

    private var shouldPlayFirstPrerollFiller: Bool {
        nextPlaybackSegmentIndex == 0 &&
        firstSegmentPrerollRemaining > 0 &&
        pendingGenerated[0] != nil &&
        state == .idle
    }

    private var shouldPlayInterSegmentFiller: Bool {
        nextPlaybackSegmentIndex > 0 &&
        interSegmentFillerRemaining > 0 &&
        pendingGenerated[nextPlaybackSegmentIndex] != nil &&
        state == .idle
    }

    private var shouldPlayComputeGapFiller: Bool {
        policy.chainFillerWhileComputeWithoutSpeech &&
        nextPlaybackSegmentIndex > 0 &&
        pendingGenerated[nextPlaybackSegmentIndex] == nil &&
        activeComputeSegments.isEmpty == false &&
        state == .idle
    }

    private var isFinished: Bool {
        allComputeFinished &&
        activeComputeSegments.isEmpty &&
        pendingGenerated.isEmpty &&
        skippedSegments.isEmpty &&
        state == .idle
    }

    private func startGenerated(
        _ audio: TuringComputeGapGeneratedAudio,
        reason: String
    ) async {
        guard audio.segmentIndex == nextPlaybackSegmentIndex else {
            pendingGenerated[audio.segmentIndex] = audio
            return
        }
        guard state == .idle else {
            pendingGenerated[audio.segmentIndex] = audio
            return
        }

        do {
            let handle = try await sink.playGeneratedSegment(audio)
            state = .playingGenerated(
                segmentIndex: audio.segmentIndex,
                handleID: handle.id
            )

            print("""
            [TuringPlaybackQueue] generated playback started
              segmentIndex: \(audio.segmentIndex)
              reason: \(reason)
              durationSeconds: \(String(format: "%.3f", handle.duration))
              handleID: \(handle.id.uuidString)
            """)

            generatedFinishTask?.cancel()
            generatedFinishTask = Task { [weak self] in
                try? await Task.sleep(
                    nanoseconds: UInt64(max(0.05, handle.duration) * 1_000_000_000)
                )
                await MainActor.run {
                    Task { @MainActor in
                        await self?.generatedFinished(
                            segmentIndex: audio.segmentIndex,
                            handleID: handle.id
                        )
                    }
                }
            }
        } catch {
            print("""
            [TuringPlaybackQueue] generated playback failed
              segmentIndex: \(audio.segmentIndex)
              error: \(error.localizedDescription)
            """)
            skippedSegments.insert(audio.segmentIndex)
            await reconcile(reason: "generatedPlaybackFailed")
        }
    }

    private func generatedFinished(
        segmentIndex: Int,
        handleID: UUID
    ) async {
        guard case .playingGenerated(segmentIndex, handleID) = state else {
            print("""
            [TuringPlaybackQueue] stale generated finish ignored
              segmentIndex: \(segmentIndex)
              handleID: \(handleID.uuidString)
              state: \(stateLogName)
            """)
            return
        }

        state = .idle
        nextPlaybackSegmentIndex = segmentIndex + 1
        if shouldRequireFillerAfterGenerated(finishedSegmentIndex: segmentIndex) {
            interSegmentFillerRemaining = max(
                interSegmentFillerRemaining,
                policy.minimumFillerClipsBetweenSegments
            )
        }

        print("""
        [TuringPlaybackQueue] generated playback finished
          segmentIndex: \(segmentIndex)
          nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex)
          interSegmentFillerRemaining: \(interSegmentFillerRemaining)
        """)

        await reconcile(reason: "generatedFinished")
    }

    private func shouldRequireFillerAfterGenerated(
        finishedSegmentIndex: Int
    ) -> Bool {
        guard policy.minimumFillerClipsBetweenSegments > 0 else {
            return false
        }
        if let expectedSegmentCount {
            return finishedSegmentIndex + 1 < expectedSegmentCount
        }
        return pendingGenerated[finishedSegmentIndex + 1] != nil ||
            activeComputeSegments.isEmpty == false ||
            allComputeFinished == false
    }

    private func startFiller(reason: String) async {
        guard state == .idle else { return }
        guard let fileURL = nextFillerURL() else {
            print("""
            [TuringPlaybackQueue] filler unavailable
              reason: noFillerFiles
            """)
            return
        }

        do {
            let label = fileURL.deletingPathExtension().lastPathComponent
            let handle = try await sink.playFillerClip(
                fileURL: fileURL,
                label: label
            )
            state = .playingFiller(handleID: handle.id)
            lastFillerFile = fileURL

            print("""
            [TuringPlaybackQueue] filler playback started
              reason: \(reason)
              clip: \(fileURL.lastPathComponent)
              durationSeconds: \(String(format: "%.3f", handle.duration))
              handleID: \(handle.id.uuidString)
            """)

            fillerFinishTask?.cancel()
            fillerFinishTask = Task { [weak self] in
                try? await Task.sleep(
                    nanoseconds: UInt64(max(0.05, handle.duration) * 1_000_000_000)
                )
                await MainActor.run {
                    Task { @MainActor in
                        await self?.fillerFinished(
                            clipURL: fileURL,
                            handleID: handle.id
                        )
                    }
                }
            }
        } catch {
            print("""
            [TuringPlaybackQueue] filler playback failed
              clip: \(fileURL.path)
              error: \(error.localizedDescription)
            """)
            await reconcile(reason: "fillerFailed")
        }
    }

    private func fillerFinished(
        clipURL: URL,
        handleID: UUID
    ) async {
        guard case .playingFiller(handleID) = state else {
            print("""
            [TuringPlaybackQueue] stale filler finish ignored
              clip: \(clipURL.lastPathComponent)
              handleID: \(handleID.uuidString)
              state: \(stateLogName)
            """)
            return
        }

        state = .idle

        print("""
        [TuringPlaybackQueue] filler playback finished
          clip: \(clipURL.lastPathComponent)
          pendingNextReady: \(pendingGenerated[nextPlaybackSegmentIndex] != nil)
        """)

        if pendingGenerated[nextPlaybackSegmentIndex] == nil,
           shouldStartDeadAirAfterFiller {
            startDeadAirAfterFiller(afterClip: clipURL)
            return
        }

        await reconcile(reason: "fillerFinished")
    }

    private var shouldStartDeadAirAfterFiller: Bool {
        policy.deadAirAfterFillerEnabled &&
        runActive &&
        state == .idle &&
        activeComputeSegments.isEmpty == false
    }

    private func startDeadAirAfterFiller(afterClip clipURL: URL) {
        guard state == .idle else { return }
        state = .deadAir

        let minSeconds = max(
            0.0,
            min(policy.deadAirMinSeconds, policy.deadAirMaxSeconds)
        )
        let maxSeconds = max(
            minSeconds,
            max(policy.deadAirMinSeconds, policy.deadAirMaxSeconds)
        )
        let seconds = Double.random(in: minSeconds...maxSeconds)

        print("""
        [TuringPlaybackQueue] dead air started
          afterClip: \(clipURL.lastPathComponent)
          nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex)
          seconds: \(String(format: "%.2f", seconds))
          interruptibleByGeneratedSpeech: true
        """)

        deadAirTask?.cancel()
        deadAirTask = Task { [weak self] in
            try? await Task.sleep(
                nanoseconds: UInt64(seconds * 1_000_000_000)
            )
            await MainActor.run {
                Task { @MainActor in
                    await self?.deadAirFinished()
                }
            }
        }
    }

    private func deadAirFinished() async {
        guard state == .deadAir else { return }
        state = .idle

        print("""
        [TuringPlaybackQueue] dead air finished
          nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex)
        """)

        await reconcile(reason: "deadAirFinished")
    }

    private func stopDeadAir(reason: String) {
        guard state == .deadAir else { return }
        deadAirTask?.cancel()
        deadAirTask = nil
        state = .idle
        print("""
        [TuringPlaybackQueue] dead air stopped
          reason: \(reason)
          nextPlaybackSegmentIndex: \(nextPlaybackSegmentIndex)
        """)
    }

    private func finishRun() async {
        runActive = false
        cancelTasks()
        await sink.cancelRun(reason: "runFinished")
        TuringAudioSessionCoordinator.shared.endPlayback(
            owner: "TuringGeneratedSpeechQueue"
        )
        print("""
        [TuringPlaybackQueue] run finished
          runID: \(runID ?? "nil")
        """)
    }

    private func cancelTasks() {
        generatedFinishTask?.cancel()
        generatedFinishTask = nil
        fillerFinishTask?.cancel()
        fillerFinishTask = nil
        deadAirTask?.cancel()
        deadAirTask = nil
    }

    private var pendingIndexesLog: String {
        let indexes = pendingGenerated.keys.sorted()
        return indexes.isEmpty ? "none" : indexes.map(String.init).joined(separator: ",")
    }

    private var stateLogName: String {
        switch state {
        case .idle:
            return "idle"
        case .playingGenerated(let segmentIndex, _):
            return "playingGenerated.\(segmentIndex)"
        case .playingFiller:
            return "playingFiller"
        case .deadAir:
            return "deadAir"
        case .cancelled:
            return "cancelled"
        }
    }

    private func nextFillerURL() -> URL? {
        if fillerQueue.isEmpty {
            fillerQueue = fillerFiles.shuffled()
        }

        if policy.avoidImmediateFillerRepeat,
           let lastFillerFile,
           fillerQueue.count > 1,
           fillerQueue.first == lastFillerFile,
           let replacementIndex = fillerQueue.firstIndex(where: { $0 != lastFillerFile }) {
            fillerQueue.swapAt(0, replacementIndex)
        }

        guard fillerQueue.isEmpty == false else { return nil }
        return fillerQueue.removeFirst()
    }

    private static func discoverFillerFiles(
        candidates: [String],
        allowedExtensions: Set<String>
    ) -> [URL] {
        var urls: [URL] = []
        let bundle = Bundle.main

        for candidate in candidates {
            if let root = bundle.url(forResource: candidate, withExtension: nil) {
                urls.append(contentsOf: filesUnder(root, allowedExtensions: allowedExtensions))
            }
            let parts = candidate.split(separator: "/").map(String.init)
            if let name = parts.last {
                let subdirectory = parts.dropLast().joined(separator: "/")
                if let root = bundle.url(
                    forResource: name,
                    withExtension: nil,
                    subdirectory: subdirectory.isEmpty ? nil : subdirectory
                ) {
                    urls.append(contentsOf: filesUnder(root, allowedExtensions: allowedExtensions))
                }
            }
        }

        return Array(Set(urls)).sorted { $0.lastPathComponent < $1.lastPathComponent }
    }

    private static func filesUnder(
        _ root: URL,
        allowedExtensions: Set<String>
    ) -> [URL] {
        guard let enumerator = FileManager.default.enumerator(
            at: root,
            includingPropertiesForKeys: [.isRegularFileKey],
            options: [.skipsHiddenFiles]
        ) else { return [] }

        var result: [URL] = []
        for case let url as URL in enumerator {
            if allowedExtensions.contains(url.pathExtension.lowercased()) {
                result.append(url)
            }
        }
        return result
    }
}
```


6. Walkie Sink With Isolated Lanes
---------------------------------

Create three persistent child lanes under the walkie emitter:

    TuringWalkieAudio_GeneratedLane
    TuringWalkieAudio_FillerLane
    TuringWalkieAudio_StaticLane

Generated speech should create a fresh child under GeneratedLane per segment.
Filler should play on FillerLane. Static should play on StaticLane.

Code:

```swift
@MainActor
final class TuringWalkieQueuedPlaybackSink: TuringQueuedPlaybackSink {
    private enum Gain {
        static let turingPlaybackDB: Float = -6.0
        static let staticLinearVolume: Float = 0.20
    }

    private weak var audioController: GravitasDemoAudioController?
    private weak var walkieEmitter: Entity?
    private let transientRoot: URL
    private var activeRunRoot: URL?
    private var generatedLane: Entity?
    private var fillerLane: Entity?
    private var staticLane: Entity?
    private var staticController: AudioPlaybackController?
    private var generatedSegmentEntities: [UUID: Entity] = [:]

    init(
        audioController: GravitasDemoAudioController,
        walkieEmitter: Entity,
        transientRoot: URL
    ) {
        self.audioController = audioController
        self.walkieEmitter = walkieEmitter
        self.transientRoot = transientRoot
    }

    func beginRun(
        runID: String,
        expectedSegmentCount: Int?
    ) async {
        let sanitizedRunID = runID
            .replacingOccurrences(of: "/", with: "_")
            .replacingOccurrences(of: ":", with: "_")
        activeRunRoot = transientRoot.appendingPathComponent(
            sanitizedRunID,
            isDirectory: true
        )
        if let activeRunRoot {
            try? FileManager.default.createDirectory(
                at: activeRunRoot,
                withIntermediateDirectories: true
            )
        }
        try? ensureLanes()
        print("""
        [TuringAudio] queued walkie sink installed
          runID: \(runID)
          expectedSegmentCount: \(expectedSegmentCount.map(String.init) ?? "streaming")
          isolatedLanes: true
        """)
    }

    func playGeneratedSegment(
        _ audio: TuringComputeGapGeneratedAudio
    ) async throws -> TuringPlaybackHandle {
        guard let audioController else {
            throw TuringWalkieAudioError.missingAudioController
        }
        try ensureLanes()
        guard let generatedLane else {
            throw TuringWalkieAudioError.missingWalkieEmitter
        }

        let fileURL = try writeGeneratedAudioFile(audio)
        let duration = Double(audio.samples.count) /
            max(1, audio.sampleRate * Double(audio.channelCount))

        let segmentEntity = Entity()
        segmentEntity.name = String(
            format: "TuringWalkieAudio_Generated_%04d",
            audio.segmentIndex
        )
        segmentEntity.position = .zero
        segmentEntity.components.set(SpatialAudioComponent())
        generatedLane.addChild(segmentEntity)

        guard let playbackID = audioController.playGeneratedTuringSpatialAudio(
            fileURL: fileURL,
            at: segmentEntity,
            volumeDB: Gain.turingPlaybackDB,
            label: "turing_walkie_qwen.segment\(audio.segmentIndex)"
        ) else {
            segmentEntity.removeFromParent()
            throw TuringWalkieAudioError.playbackStartFailed(
                "turing_walkie_qwen.segment\(audio.segmentIndex)"
            )
        }

        generatedSegmentEntities[playbackID] = segmentEntity

        print("""
        [TuringAudio] queued generated segment started
          segmentIndex: \(audio.segmentIndex)
          handleID: \(playbackID.uuidString)
          lane: TuringWalkieAudio_GeneratedLane
          entity: \(segmentEntity.name)
        """)

        return TuringPlaybackHandle(
            id: playbackID,
            label: "generated.\(audio.segmentIndex)",
            duration: duration
        )
    }

    func playFillerClip(
        fileURL: URL,
        label: String
    ) async throws -> TuringPlaybackHandle {
        guard let audioController else {
            throw TuringWalkieAudioError.missingAudioController
        }
        try ensureLanes()
        guard let fillerLane else {
            throw TuringWalkieAudioError.missingWalkieEmitter
        }

        guard let playbackID = audioController.playGeneratedTuringSpatialAudio(
            fileURL: fileURL,
            at: fillerLane,
            volumeDB: Gain.turingPlaybackDB,
            label: "turing_walkie_filler.\(label)"
        ) else {
            throw TuringWalkieAudioError.playbackStartFailed(label)
        }

        return TuringPlaybackHandle(
            id: playbackID,
            label: "filler.\(label)",
            duration: Self.durationSeconds(of: fileURL)
        )
    }

    func startStaticLoop(
        fileURL: URL,
        reason: String
    ) async throws {
        guard staticController == nil else { return }
        try ensureLanes()
        guard let staticLane else {
            throw TuringWalkieAudioError.missingWalkieEmitter
        }

        let resource = try AudioFileResource.load(
            contentsOf: fileURL,
            configuration: AudioFileResource.Configuration(
                loadingStrategy: .preload,
                shouldLoop: true
            )
        )
        let controller = staticLane.playAudio(resource)
        controller.gain = Self.decibels(
            linearVolume: Gain.staticLinearVolume
        )
        staticController = controller

        print("""
        [TuringAudio] queued static loop started
          reason: \(reason)
          lane: TuringWalkieAudio_StaticLane
        """)
    }

    func stopStaticLoop(reason: String) async {
        staticController?.stop()
        staticController = nil
    }

    func cancelRun(reason: String) async {
        staticController?.stop()
        staticController = nil
        for entity in generatedSegmentEntities.values {
            entity.removeFromParent()
        }
        generatedSegmentEntities.removeAll()

        if let activeRunRoot,
           FileManager.default.fileExists(atPath: activeRunRoot.path) {
            try? FileManager.default.removeItem(at: activeRunRoot)
        }
        activeRunRoot = nil
    }

    private func ensureLanes() throws {
        guard let walkieEmitter,
              walkieEmitter.parent != nil else {
            throw TuringWalkieAudioError.missingWalkieEmitter
        }

        if generatedLane?.parent == nil {
            generatedLane = makeLane(
                named: "TuringWalkieAudio_GeneratedLane",
                under: walkieEmitter
            )
        }
        if fillerLane?.parent == nil {
            fillerLane = makeLane(
                named: "TuringWalkieAudio_FillerLane",
                under: walkieEmitter
            )
        }
        if staticLane?.parent == nil {
            staticLane = makeLane(
                named: "TuringWalkieAudio_StaticLane",
                under: walkieEmitter
            )
        }
    }

    private func makeLane(
        named name: String,
        under root: Entity
    ) -> Entity {
        if let existing = root.children.first(where: { $0.name == name }) {
            existing.components.set(SpatialAudioComponent())
            return existing
        }
        let lane = Entity()
        lane.name = name
        lane.position = .zero
        lane.components.set(SpatialAudioComponent())
        root.addChild(lane)
        return lane
    }

    private func writeGeneratedAudioFile(
        _ audio: TuringComputeGapGeneratedAudio
    ) throws -> URL {
        // Use the existing writeGeneratedAudioFile implementation from
        // TuringWalkieSpatialPlaybackSink.
    }

    private static func durationSeconds(of fileURL: URL) -> TimeInterval {
        do {
            let file = try AVAudioFile(forReading: fileURL)
            let sampleRate = file.fileFormat.sampleRate
            guard sampleRate > 0 else { return 0 }
            return Double(file.length) / sampleRate
        } catch {
            return 0
        }
    }

    private static func decibels(linearVolume: Float) -> Double {
        guard linearVolume > 0 else { return -96.0 }
        return Double(20.0 * log10(linearVolume))
    }
}
```

9. Acceptance Logs
------------------

Expected on run:

```text
[TuringPlaybackQueue] run started
  firstSegmentPrerollFillerCount: 1
  minimumFillerClipsBetweenSegments: 0
  deadAirAfterFiller: true
  deadAirSeconds: 0.50...4.00
```

Important filler policy:

```text
No filler plays during initial Qwen compute before segment 0 is ready.
When segment 0 becomes ready, play exactly one preroll filler clip, then segment 0.
Do not force filler between generated clips when the next clip is already ready.
Only use filler after playback has started and the next required generated
segment is not ready.
```

When out-of-order Qwen completes:

```text
[TuringPlaybackQueue] compute finished
  segmentIndex: 5
  pendingIndexes: 2,5
  nextPlaybackSegmentIndex: 2
  state: playingGenerated.1
```

When real speech is active:

```text
[TuringPlaybackQueue] generated playback started
  segmentIndex: 2

// No other generated playback started until:

[TuringPlaybackQueue] generated playback finished
  segmentIndex: 2
```

When filler plays:

```text
[TuringPlaybackQueue] filler playback started
  reason: computeWithoutSpeech

// Generated ready here does not interrupt filler:

[TuringPlaybackQueue] compute finished
  segmentIndex: 3
  state: playingFiller

[TuringPlaybackQueue] filler playback finished
```

When dead air starts:

```text
[TuringPlaybackQueue] dead air started
  afterClip: big-mike-filler_umm-02_10.mp3
```

When generated becomes ready during dead air:

```text
[TuringPlaybackQueue] dead air stopped
  reason: nextGeneratedReady

[TuringPlaybackQueue] generated playback started
  segmentIndex: 3
```

Recording-safe logs:
