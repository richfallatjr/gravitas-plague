TURING FLOW STANDARDIZATION - ARCHITECT IMPLEMENTATION HANDOFF
================================================================

Repository: Gravitas Plague
Scope: Story episodic Turing Flow orchestration only
Status: implementation directive


1. GOAL
=======

The project has three Turing Flow script points implemented through different
hand-written paths. This must become one data-driven episodic runtime.

After this refactor:

- Adding ScriptPoint04 or ScriptPoint400 is resource authoring, not new Swift.
- Adding a cloned character is voice data plus clone artifacts, not a new class.
- One engine owns every Turing Flow state transition.
- One configurable playback owner handles PR, filler, and generated speech.
- One episode graph owns automatic, conversation, and external transitions.
- The physical walkie icon and debug UI observe the engine; neither owns flow.

Canonical Turing Flow:

    authored prerecording starts
    + Foundation voicePrompt computes concurrently
    + Qwen computes when the character pool is available
    -> prerecording reaches actual playback completion
    -> at least one character filler clip plays
    -> filler continues only while generated segment zero is unavailable
    -> generated TTS plays in segment-index order to actual completion
    -> conversation seed/context commits
    -> configured transition runs
    -> microphone opens when configured

No duration estimate may advance any media stage.


2. HARD BOUNDARIES
==================

Preserve these working systems:

- TuringDialogueService prompts and JSON parsing.
- Exactly two fresh Qwen instances, no shared-weight fallback.
- Base clone model and current clone artifacts.
- Big Mike and Rich 0.85 output slowdown.
- Filler weighting: <name>_<weight>.<extension>, weight 1...10.
- TuringStoryWalkiePlaybackCoordinator actual-completion bookkeeping.
- Walkie spatial emitter and RealityKit playback completion callbacks.
- Rich player/head route and Big Mike walkie-spatial route.
- Walkie static/send-static implementation.
- Dictation, room placement, portals, props, audiobook, and Horde mode.

Do not add another low-level playback queue. Standardize orchestration above the
existing playback coordinator.

```swift
struct TuringFlowDescriptor: Codable, Sendable, Hashable {
    let schemaVersion: Int
    let flowID: String
    let episodeID: String
    let prerecordingID: String
    let voicePromptID: String
    let speakerID: String
    let voiceID: String
    let conversationKey: String
    let outputContext: TuringVoiceOutputContext
    let promptStart: PromptStart
    let fillerPolicy: FillerPolicy
    let commsPolicy: CommsPolicy
    let completion: CompletionPolicy
    let failurePolicy: FailurePolicy

    enum PromptStart: String, Codable, Sendable {
        case whenPrerecordingStarts
        case duringPriorFlowLeadIn
        case whenPriorFlowPlanIsReady
    }

    struct FillerPolicy: Codable, Sendable, Hashable {
        let minimumClipsAfterPrerecording: Int
        let chainWhileSegmentZeroUnavailable: Bool
        let finishCurrentClipBeforeGenerated: Bool
        let deadAirAfterFiller: Bool
        let deadAirMinimumSeconds: Double
        let deadAirMaximumSeconds: Double
    }

    struct CommsPolicy: Codable, Sendable, Hashable {
        let playOpenBeforePrerecording: Bool
        let playSendAfterGenerated: Bool
        let responseLeadInSecondsAfterSend: Double?
        let ambientWalkieStaticDuringIncomingPlayback: Bool
    }

    struct CompletionPolicy: Codable, Sendable, Hashable {
        let nextFlowID: String?
        let transition: Transition
        let transitionDelaySeconds: Double
        let unlockConversation: Bool
        let emittedEvent: String?

        enum Transition: String, Codable, Sendable {
            case none
            case immediately
            case afterConversationTurn
            case externalEvent
        }
    }

    struct FailurePolicy: Codable, Sendable, Hashable {
        let allowPrerecordingToFinish: Bool
        let allowAlternateVoice: Bool
        let allowDeterministicSpeechFallback: Bool
        let unlockConversationAfterGenerationFailure: Bool
    }
}
```

9. GENERIC RENDERER CONTRACT
============================

```swift
actor TuringGenericBaseCloneRenderer {
    private let voice: TuringCharacterVoiceDescriptor
    private let resources: TuringBaseCloneRuntimeResources
    private let arbiter: TuringQwenCharacterPoolArbiter

    init(
        voice: TuringCharacterVoiceDescriptor,
        resources: TuringBaseCloneRuntimeResources = .init(),
        arbiter: TuringQwenCharacterPoolArbiter = .shared
    ) {
        self.voice = voice
        self.resources = resources
        self.arbiter = arbiter
    }

    func render(
        segments: [TuringSpeechSegment],
        runID: String,
        sink: any TuringGeneratedAudioPlaybackSink
    ) async throws {
        let owner = "\(voice.voiceID).\(runID)"
        await arbiter.acquire(owner: owner)
        var pool: TuringQwenNativeFreshInstancePool?

        do {
            guard let bundleRoot = Bundle.main.resourceURL else {
                throw TuringRuntimeError.invalidConfig("Missing bundle root")
            }
            let profile = try TuringQwenNativeCloneProfileLoader()
                .loadBaseCloneProfile(
                    from: bundleRoot,
                    resourcePath: voice.cloneProfileResourcePath,
                    expectedVoiceID: voice.voiceID
                )
            let model = try resources.locateBundledModel()
            let staged = try resources.stageWritableModel(from: model)
            let createdPool = try TuringQwenNativeGenerationSchedulerFactory
                .makeFresh2Pool()
            pool = createdPool
            try await createdPool.warmLoadExactlyRequestedInstances(
                modelRoot: staged,
                cloneProfile: profile,
                variantID: voice.defaultVariantID,
                performanceMode: .performance
            )
            let scheduler = TuringQwenNativeGenerationSchedulerFactory
                .makeFresh2Scheduler(instancePool: createdPool)
            let artifacts = try TuringQwenNativeCloneArtifactsLoader().load(
                from: profile.requireVariant(voice.defaultVariantID),
                expectedVoiceID: voice.voiceID
            )
            let requests = segments.enumerated().map { index, segment in
                TuringQwenNativeBaseCloneSegmentRequest(
                    segmentIndex: index,
                    text: segment.text,
                    language: "english",
                    cloneProfile: profile,
                    maxNewRows: voice.generation.maxNewRows,
                    performanceMode: .performance,
                    referenceRowLimit: artifacts.referenceRowCount,
                    referenceWindowStrategy: .full
                )
            }

            await sink.setExpectedGeneratedSegmentCount(requests.count)
            _ = try await scheduler.renderSegments(
                requests,
                runID: runID,
                skipSegmentFailures: true,
                onSegmentStarted: { _, index in
                    await sink.qwenComputeStarted(segmentIndex: index)
                },
                onSegmentFinished: { result in
                    await sink.qwenComputeFinished(
                        segmentIndex: result.segmentIndex,
                        audio: .init(
                            segmentIndex: result.segmentIndex,
                            samples: result.audio.samples,
                            sampleRate: Double(result.audio.sampleRate),
                            channelCount: 1
                        )
                    )
                },
                onSegmentSkipped: { skipped in
                    await sink.qwenComputeSkipped(
                        segmentIndex: skipped.segmentIndex,
                        reason: skipped.errorDescription
                    )
                }
            )
            await sink.qwenComputeAllFinished()
            await createdPool.unloadAll(reason: "flowFinished.\(runID)")
            pool = nil
            await arbiter.release(owner: owner)
        } catch {
            await pool?.unloadAll(reason: "flowFailed.\(runID)")
            await arbiter.release(owner: owner)
            throw error
        }
    }
}
```

Implement configurable segmentRetryCount without a Rich-specific branch.

```swift
@MainActor
struct TuringFlowPlaybackFactory {
    func make(
        flow: TuringFlowDescriptor,
        voice: TuringCharacterVoiceDescriptor
    ) -> TuringStoryWalkiePlaybackCoordinator {
        var policy = TuringStoryWalkiePlaybackCoordinator.Policy()
        policy.firstSegmentPrerollFillerCount =
            flow.fillerPolicy.minimumClipsAfterPrerecording
        policy.chainFillerFromPrerecordingToFirstGenerated =
            flow.fillerPolicy.chainWhileSegmentZeroUnavailable
        policy.completeCurrentFillerBeforeGeneratedSpeech =
            flow.fillerPolicy.finishCurrentClipBeforeGenerated
        policy.deadAirAfterFillerEnabled = flow.fillerPolicy.deadAirAfterFiller
        policy.deadAirMinSeconds = flow.fillerPolicy.deadAirMinimumSeconds
        policy.deadAirMaxSeconds = flow.fillerPolicy.deadAirMaximumSeconds
        policy.fillerDirectoryCandidates = voice.fillerDirectoryCandidates
        policy.outputProcessingPolicy = .init(
            voiceID: voice.voiceID,
            playbackRate: voice.outputProcessing.playbackRate
        )
        policy.generatedGainDB = voice.defaultGains.generatedDB
        policy.prerecordingGainDB = voice.defaultGains.prerecordingDB
        policy.fillerGainDB = voice.defaultGains.fillerDB
        policy.voiceRoute = route(for: flow.outputContext)
        return TuringStoryWalkiePlaybackCoordinator(policy: policy)
    }

    private func route(
        for context: TuringVoiceOutputContext
    ) -> TuringStoryWalkiePlaybackCoordinator.VoiceRoute {
        switch context {
        case .walkieSpatial: return .walkieSpatial
        case .walkieOutgoingGlobal: return .playerHeadTracked
        case .walkieOutgoingHeadset: return .playerHeadTracked
        case .roomGlobal: return .playerGlobal
        }
    }
}
```

Rules:

- Flow start disables physical and debug triggers; icon = busy.
- PR, Foundation, Qwen, filler, and TTS remain disabled.
- Immediate next flow remains busy between points.
- Successful unlockConversation flow sets microphone and enables interaction.
- Failure follows descriptor failure policy, not SwiftUI task cleanup.
- This gate must never reconfigure system screen recording/capture.

```swift
actor TuringFlowEngine {
    private var activeFlowID: String?
    private var state: TuringFlowState = .idle
    private let flowStore: TuringFlowStore
    private let prerecordingStore: TuringPrerecordingStore
    private let promptStore: TuringVoicePromptTriggerStore
    private let voiceRegistry: TuringCharacterVoiceRegistry
    private let dialogueService: TuringDialogueService
    private let seedStore: TuringConversationSeedStore
    private let playbackFactory: TuringFlowPlaybackFactory
    private let comms: TuringWalkieCommsFXController
    private weak var interactionGate: (any TuringFlowInteractionGate)?

    func run(
        flowID: String,
        prepared: TuringPreparedFlow? = nil
    ) async -> TuringVoiceRunResult {
        guard activeFlowID == nil else {
            return .failed("Another Turing Flow is active")
        }
        activeFlowID = flowID
        defer { activeFlowID = nil }

        do {
            let flow = try flowStore.descriptor(id: flowID)
            let prerecording = try prerecordingStore.descriptor(
                id: flow.prerecordingID
            )
            let prerecordingURL = try prerecordingStore.audioURL(
                for: prerecording
            )
            let trigger = try promptStore.descriptor(id: flow.voicePromptID)
            let voice = try voiceRegistry.descriptor(voiceID: flow.voiceID)
            try validateCrossResourceIdentity(
                flow: flow,
                prerecording: prerecording,
                trigger: trigger,
                voice: voice
            )

            await interactionGate?.setInteractionEnabled(
                false,
                reason: "flowStarted.\(flowID)"
            )
            await interactionGate?.setWalkieIconMode(
                .busy,
                reason: "flowStarted.\(flowID)"
            )

            if flow.commsPolicy.playOpenBeforePrerecording {
                try await comms.playScriptedOpenComm(reason: flowID)
            }

            let playback = await MainActor.run {
                playbackFactory.make(flow: flow, voice: voice)
            }
            await playback.beginRun(runID: flowID, expectedSegmentCount: nil)
            await playback.enqueuePrerecording(
                id: prerecording.prerecordingID,
                fileURL: prerecordingURL
            )

            let planTask = prepared?.planTask ?? makePlanTask(
                flow: flow,
                prerecording: prerecording,
                trigger: trigger
            )
            let plan = try await planTask.value
            guard plan.segments.isEmpty == false else {
                await playback.setExpectedGeneratedSegmentCount(0)
                await playback.qwenComputeAllFinished()
                await playback.waitUntilPlaybackFinished()
                return .failed("Flow returned no generated TTS segments")
            }

            await seedStore.updatePrerecording(
                id: prerecording.prerecordingID,
                transcript: prerecording.transcript,
                for: flow.conversationKey
            )
            await seedStore.updateSeed(
                plan.conversationSeed,
                for: flow.conversationKey
            )

            let renderer = TuringGenericBaseCloneRenderer(voice: voice)
            do {
                try await renderer.render(
                    segments: plan.segments,
                    runID: flowID,
                    sink: playback
                )
            } catch {
                await playback.qwenComputeFailed(
                    expectedSegmentCount: plan.segments.count,
                    reason: error.localizedDescription
                )
                await playback.waitUntilPlaybackFinished()
                throw error
            }

            await playback.waitUntilPlaybackFinished()
            let played = await playback.completedGeneratedSegmentCount()
            guard played == plan.segments.count else {
                throw TuringRuntimeError.playbackFailed(
                    "Expected \(plan.segments.count); played \(played)"
                )
            }

            if flow.commsPolicy.playSendAfterGenerated {
                try await comms.playScriptedSendComm(reason: flowID)
            }
            return try await finish(flow: flow)
        } catch {
            return .failed(error.localizedDescription)
        }
    }
}
```

Production code must publish state/events, cancel only its run token, and never
use global stop-all for normal completion.

```swift
actor TuringEpisodeFlowCoordinator {
    private let engine: TuringFlowEngine
    private var completedFlowIDs = Set<String>()
    private var conversationTurnsByKey: [String: Int] = [:]

    func start(flowID: String) async -> TuringVoiceRunResult {
        let result = await engine.run(flowID: flowID)
        if result.succeeded {
            completedFlowIDs.insert(flowID)
            await advanceIfNeeded(from: flowID)
        }
        return result
    }

    func conversationTurnCompleted(conversationKey: String) async {
        conversationTurnsByKey[conversationKey, default: 0] += 1
        await evaluateConversationTriggeredTransitions(conversationKey)
    }

    func externalEvent(_ eventID: String) async {
        await evaluateExternalTransitions(eventID)
    }
}
```

16. CROSS-RESOURCE VALIDATION
=============================

```swift
func validateCrossResourceIdentity(
    flow: TuringFlowDescriptor,
    prerecording: TuringPrerecordingDescriptor,
    trigger: TuringVoicePromptTriggerDescriptor,
    voice: TuringCharacterVoiceDescriptor
) throws {
    guard flow.speakerID == prerecording.speaker,
          flow.speakerID == trigger.speakerID,
          flow.speakerID == voice.speakerID,
          flow.voiceID == prerecording.voiceID,
          flow.voiceID == trigger.voiceID,
          flow.voiceID == voice.voiceID,
          flow.conversationKey == trigger.conversationKey,
          flow.outputContext == trigger.outputContext else {
        throw TuringRuntimeError.invalidConfig(
            "Turing Flow identity mismatch: \(flow.flowID)"
        )
    }
}
```

This is resource integrity validation, not a semantic speech gate.


17. PLAYBACK AND CONCURRENCY INVARIANTS
=======================================

1. PR starts once and plays fully.
2. Foundation/Qwen completion cannot stop PR.
3. At least one configured filler plays between PR and generated segment zero.
4. Generated-ready during filler waits for filler completion.
5. Filler chains only while segment zero is unavailable.
6. Generated segments play in index order.
7. Segment N+1 never replaces segment N.
8. Playback advances only from the active handle completion callback.
9. No Task.sleep(duration) advances PR or generated media.
10. Generated WAV cleanup follows accepted playback completion.
11. Flow success requires completedGeneratedSegmentCount == plan segment count.
12. Terminal Qwen failure calls qwenComputeFailed and releases waiters.
13. Normal completion never calls cancelAll on unrelated audio.
14. Static/open/send remain spatial at the walkie.
15. Rich voice remains player/head routed.
16. Big Mike voice remains spatial at TuringStoryWalkieTalkie_AudioEmitter.
17. Foundation may overlap PR and prior-flow lead-in.
18. Only one character pool owns resident generation resources at a time.
19. Fresh2 internally runs exactly two fresh instances.
20. A prepared next flow may own a Foundation task, but no Qwen playback events.
21. Segment zero plays as soon as PR/filler ordering permits; do not await all TTS.


18. FAILURE CONTRACT
====================

Foundation failure after PR starts:

    let PR finish
    mark generated work terminal
    no alternate speech
    no automatic transition

Qwen failure:

    let current clip finish
    call qwenComputeFailed for unresolved indices
    release Fresh2 pool and arbiter
    no alternate voice
    no automatic transition

Generated playback failure:

    do not increment completed count
    do not transition
    do not unlock conversation unless explicitly authored

Cancellation:

    cancel only the active flow/run token
    leave unrelated Story audio and system recording untouched
