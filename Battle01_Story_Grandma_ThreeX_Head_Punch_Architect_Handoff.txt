==========================================================================
1. REQUIRED PRODUCT CONTRACT
==========================================================================

Story Grandma must be approximately three times harder to stop with punches
than her Horde-mode counterpart, using this exact rule:

1. Every valid player punch detected in Grandma's head region triggers the
   appropriate head-snap sub-animation.

2. The head-snap is always an overlay. It plays over the animation already
   running, including:

   - idle
   - turning
   - walking
   - attacking
   - a full-body damage reaction

3. Every temporally eligible Story head punch performs an independent random
   Bernoulli roll with probability 1/3 (33.333333%). A successful roll becomes
   an accepted damage punch. An unsuccessful roll is overlay-only.

4. An accepted damage punch does all of the existing normal damage work:

   - increments Grandma's accepted damage-point count by one;
   - checks whether that accepted point kills her;
   - selects and plays the existing normal full-body damage/death animation;
   - applies existing knockback;
   - plays existing character damage feedback;
   - if she is attacking, interrupts/cancels that active attack.

5. The other two head punches are overlay-only punches. They must do only:

   - face-punch impact feedback;
   - side-correct head-snap overlay;
   - diagnostics.

6. An overlay-only punch must NOT:

   - increment acceptedHitCount;
   - advance Grandma toward death;
   - select or play a full-body damage animation;
   - call cancelActiveAttackForPlayerHit;
   - set activeAttack.wasCanceled;
   - clear activeAttack;
   - change combatState;
   - change followDemoState;
   - clear locomotionDeltaHandler;
   - apply knockback;
   - set escalateAfterHitReact;
   - call onCharacterDamageHit;
   - prevent the current attack damage window from damaging the player.

7. Therefore, if Grandma is in the middle of a swing, each head punch resolves
   independently:

   failed 33% roll:
     head snap overlays the swing;
     swing continues and may damage the player.

   successful 33% roll:
     head snap overlays first;
     one damage point is accepted;
     the normal full-body hit reaction starts;
     the active swing is canceled/interrupted.

8. There is no fixed sequence, pity counter, forced third hit, or grouping into
   sets of three. Consecutive successes and consecutive failures are valid.

9. Do not multiply Grandma's outgoing attack damage by three. The requested
   strength increase comes from accepting only one damage point and one
   interrupting full-body reaction for every three valid head punches.

10. Do not multiply hitsToKill. Keep Grandma's existing accepted-hit health
    value. If her configured hitsToKill is 3...5, the expected number of
    eligible Story head punches is approximately 9...15, but actual runs vary
    because every punch is an independent random trial.

5. REQUIRED HIT BRANCH ORDER
==========================================================================

The Story policy must branch before any attack cancellation, full-body clip
selection, knockback, acceptedHitCount mutation, follow reset, or locomotion
reset.

Recommended shape:

```swift
private func handleHitEvent(
    _ event: JockHandHitDetector.HitEvent
) {
    guard canReceivePlayerPunchDamage(
        currentHeadPosition: latestHeadPosition
    ) else {
        logIgnoredHit(event)
        return
    }

    guard lifecycleState == .alive else { return }
    guard !isDeadCombatState else { return }

    // Feedback shared by all valid detected head punches.
    if event.region == .head {
        onPunchHit?(event.region)
        triggerHeadSnapSubAnimation(for: event.side)
    }

    switch incomingPunchPolicy {
    case .legacyHorde:
        // Call the current Horde implementation with no behavior changes.
        handleLegacyHordeDamageHit(event)

    case .storyGrandmaThreeX:
        handleStoryGrandmaHeadPunch(event)
    }
}
```

Do not call `onPunchHit` or `triggerHeadSnapSubAnimation` a second time from the
extracted legacy function.

Story branch:

```swift
private func handleStoryGrandmaHeadPunch(
    _ event: JockHandHitDetector.HitEvent
) {
    // The requested one-in-three rule applies to head punches only.
    guard event.region == .head else {
        performAcceptedDamageHit(
            event,
            acceptedAt: CACurrentMediaTime(),
            source: .storyNonHead
        )
        return
    }

    let now = CACurrentMediaTime()
    let temporalGate = shouldAcceptEnemyDamage(
        sourceID: hordeID,
        now: now
    )

    guard temporalGate.accepted else {
        logStoryPunchDecision(
            event: event,
            decision: "duplicate_feedback_only",
            randomRollPerformed: false,
            randomRollAccepted: nil,
            temporalGateAccepted: false
        )
        return
    }

    let damageAccepted = storyHeadPunchDamageRoller.rollDamageAcceptance()

    if !damageAccepted {
        // Critical: return before touching attack/combat/follow state.
        logStoryPunchDecision(
            event: event,
            decision: "overlay_only",
            randomRollPerformed: true,
            randomRollAccepted: false,
            temporalGateAccepted: true
        )
        return
    }

    lastDamageAcceptedAtBySourceID[hordeID] = now

    logStoryPunchDecision(
        event: event,
        decision: "damage_and_interrupt",
        randomRollPerformed: true,
        randomRollAccepted: true,
        temporalGateAccepted: true
    )

    performAcceptedDamageHit(
        event,
        acceptedAt: now,
        source: .storyRandomOneThirdHeadPunch
    )
}
```

The exact helper names may follow local style, but the ordering may not change.

`performAcceptedDamageHit` owns only the normal accepted-damage path:

```swift
private func performAcceptedDamageHit(
    _ event: JockHandHitDetector.HitEvent,
    acceptedAt now: TimeInterval,
    source: JockAcceptedDamageSource
) {
    let nextAcceptedHitCount = acceptedHitCount + 1
    let shouldDie = nextAcceptedHitCount >= hitsToKill
    let finalDamage: JockHitDamageLevel = shouldDie
        ? .death
        : event.damageLevel

    acceptedHitCount = nextAcceptedHitCount

    let isStrongHit = attackConfiguration
        .escalationDamageLevels
        .contains(finalDamage)

    if isStrongHit {
        escalateAfterHitReact = true
    }

    if case .attacking = combatState {
        cancelActiveAttackForPlayerHit(
            isStrongHit: isStrongHit
        )
    }

    // Continue with the existing accepted damage/death implementation:
    // clip selection, follow/locomotion reset, knockback, death handling,
    // onCharacterDamageHit, combatState .hitReaction, and driver.playClip.
}
```

Important:

The head snap must be triggered before `performAcceptedDamageHit`. Calling
`driver.playClip` for the full-body damage reaction does not clear the current
active sub-animation list, so the head snap remains layered over the newly
selected damage base clip.
